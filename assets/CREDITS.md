# Credits

Every model in this folder is a copy of a file from a free asset pack, unchanged
(`characters/hero_head_texture.png` is the Knight's texture with the hair darkened). All
packs are CC0 (public domain): they can be used in a commercial game without asking or
crediting, but the author deserves the thanks.

The jungle palms are the Kenney models merged and tinted in code (`PalmModels`). The Kenney decoration is merged and tinted in code (`NatureModels`) so it sits with the KayKit greens. The slimes, the Rey Slime's crown, the bat, the mushroom, the wolf, the goblin, the carnivorous plant and the bushes are built in code (`BattleActor`, `LowPoly`); the Bruja del bosque is the Mage tinted purple; the Señor de la Niebla is the Skeleton_Mage scaled and tinted, with an aura built in code.
