# Versión 2.6.0 y 2.6.1: plan de implementación (la interfaz con el design system)

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Modelos:** cada tarea la implementa un subagente **sonnet** y la revisa otro subagente **sonnet** (nada de haiku). El controlador no escribe código.

**Tamaño y reparto:** el spec (M-62 a M-66) toca todas las pantallas del juego; en una sola versión serían tareas enormes y una versión sin publicar durante mucho tiempo. **Se parte en dos versiones, cada una publicable sola:**

- **Parte A — 2.6.0** (M-62, M-63, M-64): `UiTokens` y `UiTheme`, las dos letras, la fila elegida con el cursor ▶ y cada pantalla pasada a tokens y estilos de tipo. Al acabarla el juego ya se ve con el design system: colores de la paleta (también el verde nuevo de EXP, el gris nuevo y la sombra de ventana, que vienen solos con los tokens), Nunito y Baloo 2, cursor en todos los menús. Tasks A1-A10.
- **Parte B — 2.6.1** (M-65, M-66): la opción «Alto contraste», el repaso de textos y los componentes que añaden algo que hoy no existe (aviso con tono, ▼ del diálogo, PV críticos, insignia «Aturdido», «¡Crítico!», separador del HeroPanel, tarjeta del resultado). Tasks B1-B6.

**Goal:** Llevar toda la interfaz al Villaclaro Design System (`docs/boost/design-system/`). Spec: `docs/legacy/specs/2026-11-13-version-2-6-0-design.md`. Anexo con el inventario de cada valor a mano (archivo:línea → token): `docs/legacy/plans/2026-11-13-version-2-6-0-inventario.md`.

**Architecture:** Tres clases nuevas en `scripts/ui/`: `UiTokens` (los valores, generados de `tokens.json`), `UiTheme` (el `Theme` en código, las letras como `FontVariation`, las variaciones de tipo y los ayudantes `menu_row()`, `add_cursor()`, `style_label()`, `style_3d()`) y `MenuCursor` (el ▶ y el fondo de la fila elegida de una ventana). `DisplaySettings.apply()` aplica el tema (también al cambiar una opción). `UiStyle`, `StatBar` y `BattleHud.make_window()` quedan como fachadas finas. Las pantallas dejan de escribir colores y tamaños: usan variaciones del tema (`theme_type_variation`) o `UiTokens.color()`.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Correcciones al spec y al design system (lo medido y el código mandan)

Comprobado en Godot 4.7.2 con un proyecto vacío del scratchpad (`plan/proj/api_check.gd`, `api_check2.gd`) y con el código de la rama.

1. **El tema por defecto pone letra y tamaño a cada tipo.** La propuesta `ui_theme.gd.txt` pone `theme.default_font` y `default_font_size` y fusiona con `merge_with()`. Medido: el tema por defecto del motor tiene `font` **y** `font_size` 16 propios en `Label`, `Button`, `Label3D`, `LineEdit`, `RichTextLabel`, `PanelContainer`, `TooltipLabel` y veinte tipos más, así que cambiar solo la letra por defecto no cambia ningún control. **Decisión:** `UiTheme.apply()` recorre `get_font_type_list()` y `get_font_size_type_list()` del tema por defecto y pone a cada tipo la letra `ui` y el tamaño `body`, y después fusiona `build()`. (`merge_with()` sí copia colores, estilos y `default_font_size`: medido.)
2. **Un botón `flat` no dibuja sus estilos ni toma su relleno.** La propuesta hace de cada fila un `Button` plano con estilos `normal` / `hover` / `pressed`; un botón plano no los dibuja y su texto no se aparta para el cursor (por eso hoy existe `UiStyle.fit_finger()`). **Decisión:** las filas dejan de ser planas (`UiTheme.menu_row()`); su estilo `normal` es un `StyleBoxEmpty` con el hueco del cursor, así que siguen sin fondo. El **fondo de la fila elegida no es el estilo `focus`** (el motor puede dibujarlo encima del texto): lo dibuja `MenuCursor` con un `Panel` propio por detrás de las filas. `focus` queda vacío y `hover` sin fondo; el ratón mueve el foco (`menu_row()` conecta `mouse_entered` → `grab_focus()`), así nunca hay dos filas marcadas.
3. **`MenuCursor` de la propuesta deja dos cursores** cuando el foco pasa a otra ventana (no borra `_target`), se ve aunque el botón haya perdido el foco y se sale de una `ScrollBox`. **Decisión:** `_target` vuelve a `null` si el foco sale de su ventana; solo se ve si su fila tiene el foco y está entera dentro de su `ScrollContainer`. En un selector o un deslizador, apunta a la fila de opción que lo contiene; las teclas del nombre y las tarjetas del bestiario dibujan su propio marco (variaciones `KEY` y `CARD_HIT`) y no llevan cursor.
4. **Nunito no es más ancha.** El spec y la migración dicen que Nunito es algo más ancha que la letra del motor. Medido a 24 px: a peso 700 es un 2-5 % **más estrecha** en palabras («Nueva partida» 157 px frente a 166, «Hablar · Granjero» 191 frente a 200) y un 1-4 % más ancha en cifras y a peso 800 («PV 420/420» 133-134 frente a 128). Su alto de línea es el mismo (34 px). **Lo que de verdad crece es Baloo 2:** 39 px de alto a 24 frente a 34 (×1,625 del tamaño). Afecta al logotipo, al subtítulo, al rótulo de lugar, a los créditos y al «Fin». **Decisión:** cada estilo `display` es una `FontVariation` con `spacing_top` / `spacing_bottom` negativos que dejan su alto en el `lineHeight` de `tokens.json` (1,0 a 1,2); el riesgo de encaje real está en el **hueco del cursor** (+38 px de ancho por fila, ver Decisiones) y en el **alto de las filas** de escritorio (40 en vez de 34).
5. **`title-l` y `title-m` son de la familia `display`** (Baloo 2) según `tokens.json`; la propuesta solo usa Baloo 2 en `DisplayLabel`. **Decisión:** la tabla de estilos de `UiTokens` (`TYPE`) lleva la familia de cada uno y `UiTheme.font_for(style)` la respeta.
6. **La sombra no tiene token en la propuesta.** `ui_theme.gd.txt` escribe `Color(0, 0, 0, 0.45)`, 6 y (0, 4) a mano. **Decisión:** `UiTokens.SHADOW_COLOR`, `SHADOW_SIZE`, `SHADOW_OFFSET` (de `shadow-window` de `tokens.json`: `#00000073`, «shadow_size 6, shadow_offset (0, 4)»).
7. **`UiTokens.color()` no vale en una `const`.** Hoy muchos archivos hacen `const MP_COLOR := StatBar.MP`. **Decisión:** las fachadas guardan **nombres de token** (`StatBar.HP := &"stat-hp"`), y el color se pide al usarlo; así el alto contraste también llega a lo que se dibuja a mano (`StatBar._draw()`).
8. **La escritura letra a letra del diálogo no existe.** `DialogueBox` muestra cada frase entera; solo `BattleHud` escribe letra a letra. El componente DialogueBox dice «frase escribiéndose letra a letra». **Decisión:** no se añade (el spec no cambia la estructura); el ▼ (B2) sale cuando la frase espera, que en el diálogo es en cuanto aparece.
9. **El aviso dura 2 s, no 4.** `World.NOTICE_TIME` es 2.0; Notice dice 0,2 s + 4 s + 0,2 s. **Decisión:** manda el design system (B2: `NOTICE_TIME` 4.0 y los dos fundidos de 0,2 s). La línea «Misión cumplida» del HeroPanel ya dura 4 s.
10. **La elección de compañero no está en `layer-overlay`.** `tokens.json` dice que `layer-overlay` 11 es para «créditos, elección de compañero»; la elección es la tienda «Compañeros» de `ShopWindow`, capa 4. **Decisión:** se queda en `LAYER_SHOP`; no hace falta ninguna capa nueva.
11. **NameEntry:** el spec dice «`NameEntry` y su rejilla usan `body`»; `tokens.json` dice que `display-m` es para el «nombre del héroe al escribirlo» (la tabla de migración: 44 → 48). **Decisión:** el nombre que se escribe va en `display-m`; la rejilla, sus filas y el resto, en `body`.
12. **Subtítulo en el móvil.** TitleLogo pide `title-l` para el subtítulo y `display-l` para el logotipo en el móvil; hoy el móvil usa 64 / 26 para que el menú quepa. **Decisión:** en el móvil el subtítulo baja un estilo, a `title-m` (como el logotipo baja de `display-xl` a `display-l`); lo que no quepa se arregla moviendo el menú (`TOUCH_MENU_TOP`), no el estilo.
13. **El bestiario usa el oro para «familia completa».** `bestiary_page.gd:63` pinta el título de una familia completa en `StatBar.GOLD`. Con «un color, un significado», el oro es dinero. **Decisión:** completa en `text-positive`, incompleta en `text-accent` (la palabra del premio ya dice que está completa, nunca solo el color).
14. **«Misión cumplida» del HeroPanel en oro** (`world.gd:1173`): igual que el anterior, pasa a `text-positive`.
15. **Celdas de mazmorra del cuadro del mapa** (`explored_map.gd:15-18`: roca, suelo, escaleras, puerta): el design system solo nombra `world-meadow` y `world-path`. **Decisión:** campo y camino pasan a sus tokens; las otras cuatro se quedan como constantes de `ExploredMap` (son la referencia del mundo, como los demás colores 3D).
16. **`README.md` del design system** dice que las licencias están en `licenses/`, y TitleLogo pone «v2.4.1» de ejemplo: en el juego las licencias son `assets/fonts/OFL-*.txt`; no se toca el design system (es una copia del artifact del usuario).
17. **Glifos:** comprobado que Nunito y Baloo 2 tienen **todos** los caracteres no ASCII que usan los textos de `scripts/` y `data/` (á é í ó ú ñ ¡ ¿ « » · × — −, mayúsculas con tilde). El ▶, los ▲▼ y el ☰ ya se dibujan, no son glifos.

## Waits WAIT frames, saves out/<name>.png and prints every window or button off the screen.
func _shot(shot: String) -> void:
	for i in WAIT:
		await process_frame
	root.get_texture().get_image().save_png(_out.path_join(shot + ".png"))
	var screen := Rect2(Vector2.ZERO, root.get_visible_rect().size)
	var bad := 0
	for node in root.find_children("*", "Control", true, false):
		var control := node as Control
		if not (control is PanelContainer or control is Button) or not control.is_visible_in_tree():
			continue
		if _in_scroll(control):
			continue  # a ScrollBox shows it by scrolling
		if not screen.grow(1.0).encloses(control.get_global_rect()):
			bad += 1
			print("NO CABE %s: %s %s" % [shot, control.get_path(), control.get_global_rect()])
	print("%s: %s" % [shot, "cabe" if bad == 0 else "%d fuera" % bad])


func _in_scroll(control: Control) -> bool:
	var node := control.get_parent()
	while node != null:
		if node is ScrollContainer:
			return true
		node = node.get_parent()
	return false

## The gold ▶ and the background of the chosen row of one window (design system, M-63). It
## follows the focused control when it is inside its window: a plain menu row, or, for a
## selector (UiTheme.SELECTOR) or a slider, the option row holding it. Keys and bestiary cards
## draw their own frame and get no cursor. Drawn, not a glyph, so the web shows it the same.
## Put it on with UiTheme.add_cursor(window): the cursor is the window's last child (over the
## rows) and its background the first (under them); both are top level, so the window's
## layout ignores them.

var _target: Control
var _back: Panel


func _init() -> void:
	mouse_filter = Control.MOUSE_FILTER_IGNORE
	top_level = true
	size = Vector2(UiTokens.CURSOR_SIZE, UiTokens.CURSOR_SIZE)


func _ready() -> void:
	_back = Panel.new()
	_back.theme_type_variation = UiTheme.SELECTED_ROW
	_back.mouse_filter = Control.MOUSE_FILTER_IGNORE
	_back.top_level = true
	_back.hide()
	get_parent().add_child.call_deferred(_back)
	get_parent().move_child.call_deferred(_back, 0)
	get_viewport().gui_focus_changed.connect(_on_focus)
	hide()


func _on_focus(control: Control) -> void:
	_target = _row_of(control) if get_parent().is_ancestor_of(control) else null


static func _row_of(control: Control) -> Control:
	if control is Range or (control is Button and control.theme_type_variation == UiTheme.SELECTOR):
		return control.get_parent() as Control
	if control is Button and control.theme_type_variation == &"":
		return control
	return null


func _process(_delta: float) -> void:
	var shown := _target != null and is_instance_valid(_target) and _target.is_visible_in_tree() \
		and _holds_focus() and _inside_scroll()
	visible = shown
	if _back:
		_back.visible = shown
	if not shown:
		return
	var rect := _target.get_global_rect()
	_back.global_position = rect.position
	_back.size = rect.size
	var inset := UiTokens.SPACE_1 if Device.is_touch() else UiTokens.SPACE_2
	global_position = Vector2(rect.position.x + inset, rect.position.y + (rect.size.y - size.y) / 2.0).round()


func _holds_focus() -> bool:
	var owner := get_viewport().gui_get_focus_owner()
	return owner != null and (owner == _target or _target.is_ancestor_of(owner))


## False while the row is (partly) scrolled out of its ScrollContainer.
func _inside_scroll() -> bool:
	var node := _target.get_parent()
	while node != null and node != get_parent():
		if node is ScrollContainer:
			return (node as Control).get_global_rect().grow(1.0).encloses(_target.get_global_rect())
		node = node.get_parent()
	return true


func _notification(what: int) -> void:
	if what == NOTIFICATION_THEME_CHANGED:
		queue_redraw()


func _draw() -> void:
	var s := float(UiTokens.CURSOR_SIZE)
	draw_colored_polygon(PackedVector2Array([Vector2(0, 0), Vector2(s * 0.8, s / 2.0), Vector2(0, s)]),
		UiTokens.color(&"border-focus"))
