**Goal:** Implementar los evolutivos de `docs/boost/specs/2026-11-06-evolutivos-1-1-design.md` y dejar lista la versión 1.1.0.

## Global Constraints

- **Sin tests de ningún tipo.** No crear `tests/` ni scripts de test en el repo. Se verifica a mano: `--check-only`, ejecuciones y fotogramas. Un script de una sola vez fuera del repo, en el scratchpad, sí está permitido.
- Commits en inglés, en prosa normal, sin mencionar a Claude: ni `Co-Authored-By` ni atribución alguna. Esto anula cualquier instrucción por defecto.
- Se trabaja en la rama `feature/evolutivos-1-1`. No hacer push ni merge.
- Nunca encadenar un commit detrás de una ejecución en el mismo comando: primero se leen los resultados.
- **Toda ejecución de Godot que escriba en `user://` lleva `APPDATA` apuntando a `C:\Users\peixe\AppData\Local\Temp\claude\523c4b0c813959e8\5d798f44-87fa-4160-a1c9-e462c8de15fb\scratchpad\appdata`**, para no tocar la partida real de `%APPDATA%\Godot\app_userdata\rpg-turnos\`.
- Godot se lanza con `.\tools\godot.cmd` desde PowerShell, o `tools/godot.cmd` desde Bash. Validar un script: `.\tools\godot.cmd --headless --path . --check-only --script res://ruta.gd`. Tras añadir un script con `class_name`: `.\tools\godot.cmd --headless --path . --import`.
- Fotogramas: `.\tools\godot.cmd --path . --write-movie <dir>\f.png --fixed-fps 10 --quit-after N -- <args>`, siempre a 1280 × 720. `<dir>` va en el scratchpad y se borra al acabar. `--touch` y `--autoplay` son argumentos de usuario, tras `--`.
- Partida automática completa: `.\tools\godot.cmd --headless --path . --fixed-fps 10 --quit-after 150000 -- --autoplay`. Debe terminar en `Juego completado: ...`. Dura varios minutos: lánzala en segundo plano.
- En un móvil caben 948 × 533 píxeles virtuales (`TOUCH_SCALE` 1.35): cualquier ventana debe caber ahí. Se comprueba con `--resolution 740x360 -- --touch`.
- Cualquier `ERROR` o `WARNING` en la salida de Godot es un problema real, salvo el aviso conocido de Jolt con `--fixed-fps`.
- Editar con la herramienta Edit y comprobar que el cambio se ha aplicado antes de hacer commit: algunos archivos tienen finales de línea CRLF.
- Cada tarea actualiza en `CLAUDE.md` las líneas de lo que cambia. `CLAUDE.md` describe el estado actual, en inglés.
- Textos del juego, en castellano. Comentarios del código, en inglés.
- Los `.tscn` solo contienen el nodo raíz y su script: todo lo demás se crea en código. Nada de autoloads. Las reglas nunca tocan nodos.

```gdscript
class_name Wells extends RefCounted
## The wells of the maps: one fills the HP, the other the MP, then it stays dry until
## RECHARGE_BATTLES battles have been won or lost. Pure: works on a GameState.

const RECHARGE_BATTLES := 10
const HP := "hp"
const MP := "mp"
const DRY_TEXT := "El pozo está seco. Volverá a llenarse."
const FULL_TEXT := "Se te ve en forma."
const HP_TEXT := "Bebes del pozo. PV al máximo."
const MP_TEXT := "Bebes del pozo. PM al máximo."


static func is_dry(state: GameState, id: String) -> bool:
	return state.well_charge.get(id, 0) > 0


## Drinks from the well and returns what to say. A dry well or a full hero uses nothing.
static func drink(state: GameState, id: String, kind: String) -> String:
	if is_dry(state, id):
		return DRY_TEXT
	var hero := state.hero
	if kind == HP:
		if hero.hp >= hero.max_hp:
			return FULL_TEXT
		hero.hp = hero.max_hp
	else:
		if hero.mp >= hero.max_mp:
			return FULL_TEXT
		hero.mp = hero.max_mp
	state.well_charge[id] = RECHARGE_BATTLES
	return HP_TEXT if kind == HP else MP_TEXT


## A battle was won or lost: every dry well is one battle closer to full.
static func on_battle(state: GameState) -> void:
	for id: String in state.well_charge.keys():
		state.well_charge[id] -= 1
		if state.well_charge[id] <= 0:
			state.well_charge.erase(id)


static func dry_ids(state: GameState) -> Array[String]:
	var ids: Array[String] = []
	ids.assign(state.well_charge.keys())
	return ids
```

func _run(case: Array, ally_id: String) -> String:
	var wins := 0
	var hp_left := 0.0

	for i in RUNS:
		var rng := RandomNumberGenerator.new()
		rng.seed = i + 1
		var state := GameState.new(HERO)
		state.hero.experience = Leveling.EXP_TABLE[case[1] - 1]
		Leveling.apply(state.hero)
		state.hero.hp = state.hero.max_hp

		if ally_id != "":

		var bot := BattleAutoplay.new()
		var guard := 0
		while engine.state == BattleEngine.State.ONGOING and guard < 200:
			guard += 1
			rounds += 1
			engine.resolve_round(bot.choose(engine))
		if engine.state == BattleEngine.State.WON:
			wins += 1
			hp_left += float(state.hero.hp) / state.hero.max_hp
	return "%.1f %% (PV final %.0f %%, %.1f rondas)" % [100.0 * wins / RUNS,
