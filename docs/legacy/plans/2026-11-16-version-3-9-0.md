# Version 3.9.0: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The spec `docs/boost/specs/2026-11-16-version-3-9-0-design.md`:

- M-121: GUT 9.7.1 vendored in `addons/gut/` (left out of every export) and about 160 unit tests of the pure rules and the data in `tests/`, run with one command;
- M-122: GitHub Actions runs them on every push to `develop` (`.github/workflows/tests.yml`);
- M-123: CLAUDE.md's «No tests — ever» becomes «Tests», and the autoplay skill and the QA brief follow.

Then the 3.9.0 release. The game does not change: no rule, data, text or balance; the save stays at version 16.

**Architecture:** Tests only call the pure rules (`RefCounted` / `Resource`: `BattleEngine`, `Leveling`, `SaveData`, `Shop`, `QuestLog`, `ClosingLands`, `StoryState`...) and read `data/`. No game script changes: `BattleEngine` already takes its `RandomNumberGenerator`, so a test passes a seeded one. `tests/` mirrors `scripts/` (`tests/<folder>/test_<script>.gd`, `extends GutTest`, no `class_name`), and `tests/fixtures.gd` (preloaded, no `class_name`) builds states, fighters, spells, battles and older saves. GUT runs headless as a `SceneTree` script (`--script res://addons/gut/gut_cmdln.gd`) and reads `res://.gutconfig.json`; it exits 1 when a test fails.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, GUT 9.7.1, Git Bash, GitHub Actions (ubuntu-latest).

## Global Constraints

The project's rules (CLAUDE.md), then the spec's decision table, verbatim.

- **Tests are allowed now, for pure rules and data only.** The user lifted «No tests — ever» on 2026-11-16; Task 1 rewrites that section of CLAUDE.md in the same commit that adds `tests/`. Never a test of a node, a scene, a constructor, the UI, visuals, sound, `InputMap` or files.
  - No test calls `SaveStore`, `FileAccess` or `DirAccess`, or writes `user://`.
  - No test changes a loaded resource (`data/*.tres`, `Fx.HERO`, `EnemyLibrary.data()`): it works on `GameState.new()` (the hero duplicated), on `.duplicate()` copies or on fighters made in the test.
  - No test spells a `"--..."` flag: it uses `RunFlags`' constants.
- **No game code changes.** If a test written here fails on the merged code because the game (or its data) is wrong, **stop and report**: the fix is a separate decision. Never loosen a test to make it pass. If the test's assumption is what is wrong, say so and fix the test.
- **The user's real save is never touched.**

## BattleEngine: damage and its spread, defending, the hero's spells growing with his level
## (3.5.0), weaknesses, items before a faster enemy (3.5.0), fleeing, surprises, poison, silence,
## immunity, the Pluma de fénix, a boss's phase, the difficulty, medals and quest items. Every
## roll goes through a seeded generator; a test asserts what holds for every roll (bounds over
## SEEDS seeds, or a rigged fight), never one seed's numbers.

const Fx := preload("res://tests/fixtures.gd")
const SEEDS := 200


func test_a_blow_hurts_within_the_spread_and_a_crit_ignores_defense() -> void:
	var hits := 0
	for s in SEEDS:
		var events := Fx.engine(Fx.fighter("hero", 100, 40), Fx.fighter("foe", 9999, 1, 20), s) \
			.resolve_round(BattleEngine.cmd_attack(0))
		for hit in Fx.hits_on(events, 0):
			hits += 1
			if hit.crit:
				# 40 x CRIT_MULT 1.5 = 60, DEF ignored, x 0.875..1.125
				assert_between(hit.amount, 52, 68, "crit, seed %d" % s)
			else:
				# 40 - 20 / 2 = 30, x 0.875..1.125
				assert_between(hit.amount, 26, 34, "hit, seed %d" % s)
	assert_gt(hits, 150, "MISS_CHANCE is 5 %")


func test_defending_halves_the_blows_taken() -> void:
	var worst_defending := 0
	var worst_open := 0
	for s in SEEDS:
		for defend in [true, false]:
			var foe := Fx.fighter("foe", 9999, 50, 0, 1)
			foe.ai_weights = {BattleEngine.CMD_ATTACK: 1.0}
			var cmd := BattleEngine.cmd_defend() if defend else BattleEngine.cmd_attack(0)
			var events := Fx.engine(Fx.fighter("hero", 9999, 1, 0, 1), foe, s).resolve_round(cmd)
			for hit in Fx.hits_on(events, BattleEvent.HERO):

				else:
					worst_open = maxi(worst_open, hit.amount)
