# Versión 2.5.0: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Modelos:** cada tarea la implementa un subagente **sonnet** y la revisa otro subagente **sonnet** (nada de haiku). El controlador no escribe código.

**Tamaño:** doce tareas, de tamaño parecido a la 2.4.0. No hace falta partirla. Si hubiera que hacerlo, el corte natural es **2.5.0** = Tasks 1-7 y 10-12 (medallas, Coleccionistas, misiones, grupos, Slime de Metal: lo que cambia el juego) y **2.5.1** = Tasks 8 y 9 (el fuego y el portal: solo gráficos, sin dependencias con lo demás).

**Goal:** Las seis ideas del registro (M-56 a M-61): las medallas pequeñas caen de los enemigos y el Coleccionista está en cada pueblo; más grupos de monstruos en la v1 y grupos que vuelven poco a poco en todas las zonas; el Slime de Metal a la mitad de velocidad; un portal del Ala de viaje con marco, remolino, chispas y luz; una misión opcional más en la mina y otra en el castillo; un fuego de verdad en antorchas y hogueras. Spec: `docs/boost/specs/2026-11-13-version-2-5-0-design.md`.

**Architecture:** Reglas pequeñas en clases puras y datos. Nuevo en código: `Medals` sin posiciones (`DROP_CHANCE`, `next_missing()`, `talk(state, zone_id)` con `AWAY_LINE`); `BattleEngine.medals_carried` / `medal_chance` / `medals_won` y el `DROP` de `Inventory.MEDAL`; `MonsterGroups.refill_spot()` y la repoblación de `World` (`REFILL_S`, `REFILL_GAP`, `BattleActor.play_fade_in()`); dos misiones de datos (`aranas`, `olla`), el look `POT`, misiones ofrecidas y entregadas en una posada (`Game._figure_with_quest()`); `Flame` (`scripts/world/flame.gd`, `shaders/flame.gdshader`), que usan `BattleStage.add_flame()` y ahora también las antorchas de `DungeonMap`; `TravelPortal` (`scripts/world/travel_portal.gd`, `shaders/portal_swirl.gdshader`) en lugar del óvalo de `World._build_portal()`.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Correcciones al spec (el código manda)

1. **M-57, la mina, planta 3:** el spec pide 7 grupos en `mina_3`, pero con `MonsterGroups.MIN_GAP` 8 m solo **caben 5** (medido con `MonsterGroups.spots(zone, 40, rng)` y ocho semillas: siempre 5). `mina_1` admite 9-10 y `mina_2` 10-11. **Decisión:** `mina_1` y `mina_2` pasan a 9, `mina_3` se queda en 5. Lo demás cabe de sobra (pradera 19-23, bosque 19-26, patio 19-20, trono 20-22).
2. **M-61, las antorchas de la mina y el castillo:** el spec dice que usan `BattleStage.add_flame()`; no es así: `DungeonMap._add_torch()` (`dungeon_map.gd:479`) construye su propia esfera y su luz, y el parpadeo vive en `DungeonMap._process()` (`dungeon_map.gd:139-143`, `_lights`). **Decisión:** `DungeonMap._add_torch()` pasa a llamar a `BattleStage.add_flame()` (con un nuevo parámetro `light_range`), y el parpadeo se va a la llama (`Flame`), de modo que las antorchas del mapa, las de los fondos de combate y las hogueras cambian a la vez, como quiere el spec.
3. **M-60, la Posadera da la misión:** hoy una posada solo **entrega** un aviso que espera (`Game._figure_with_report("inn", ...)`, `game.gd:890`), nunca **ofrece** una misión; y `QuestLog.problems()` avisa de cualquier figura de entrega que no sea `npc` ni `quest`. Además el "!" de una figura con letrero ("Posada") saldría encima del letrero. **Decisión:** `_figure_with_report()` pasa a `_figure_with_quest()`, que usa `QuestLog.markers()` (ofertas "!" y entregas "?"), `problems()` acepta `inn` y `shop` (Game entrega en ellas desde la 2.4.0), y `World._build_mark()` sube la marca por encima del letrero.
4. **M-56, `--autoplay-zone=medallas`:** con el 2 % por enemigo, reunir 12 medallas pide unos 600 enemigos: la partida automática tardaría horas. **Decisión:** en esa partida (y solo en ella) la probabilidad es `Game.MEDAL_TOUR_CHANCE` 0,25: la vuelta comprueba el camino (caídas, aviso, Coleccionista, premios), no la cifra. La cifra se mide con la v1 entera (Task 10).
5. **M-59, `PortalRing`:** el spec permite que use el shader nuevo. **Decisión:** no se toca (ya se ve bien y es el portal de la historia); el shader nuevo solo lo usa `TravelPortal`.
6. **M-56, el Coleccionista de Villaclaro:** el spec pide un punto de ruta a menos de 2,5 m de cada Coleccionista. El de Villaclaro (10, −24,5) está detrás de la casa de la posada; un punto en línea recta desde allí hacia el norte de la aldea atraviesa la casa (`house_B_red` en (5,5, −25)). **Decisión:** el punto nuevo (9, −22,5) va y vuelve por (4,6, −22,3).

## Decisiones tomadas en el plan (el spec las dejaba abiertas)

- `Medals.MEDALS` pasa a `Array[String]` con los doce ids de hoy en el mismo orden (`SaveData._valid_medals()` usa `.has()` y `.size()`, que valen igual).
- La medalla caída **no** entra en el inventario: `BattleEngine` cuenta `medals_won` y pone `Inventory.MEDAL` en `drops_won` (para la línea "+1 Medalla pequeña" de la pantalla de victoria); `Game` llama a `Medals.take(state, Medals.next_missing(state))` por cada una.
- Un enemigo **ayudante** llamado por un jefe (el Slime de arena del Gusano, el centinela de ayuda) sí puede dejar medalla: no es jefe.
- El chiste del Coleccionista (`AWAY_LINE`) sale la **primera vez** que se le habla en cada pueblo que no es Villaclaro, si ya se le conocía (bandera `coleccionista_<zona>`). La primera vez que se le conoce, esté donde esté, dice `INTRO`. Una Partida nueva + borra esas banderas: el chiste vuelve, y está bien.
- La Olla (`olla`) no está en la ruta automática (el spec la quiere a 6 m o más): la partida automática la acepta pero no la termina. La de las arañas sí, si la ruta pasa por la Minera (el punto nuevo del refugio queda a menos de 2,5 m de los dos).
- `--autoplay-zone=medallas` termina hablando con el Coleccionista en Villaclaro **y luego en la aldea del bosque**, para ver el chiste.
- El marco del portal se hace en código con bloques (`BoxMesh` fundidos en una malla, como la base de `PortalRing`), en piedra clara `Color(0.6, 0.57, 0.53)`; nada de modelos nuevos.
- Las brasas usan las banderas que ya existen: ninguna si `ZoneParticles.enabled` es falso (calidad baja), la mitad si `ZoneParticles.half` (un móvil).

```gdscript
extends SceneTree
## Photos of world maps (the hero placed at each VIEWS point, the map camera on him) and of a
## mine battle, with the draw calls of each one.
## godot --path <repo> --resolution 1280x720 --script <this> -- <out dir> [groups] [low] [touch]
## "groups": the monster groups on; "low": low quality (no particles, half grass); "touch":
## ZoneParticles.half (a phone's particle counts).

## zone -> [[hero point, extra]]: "portal" opens the Ala's portal at the zone's portal_pos and
## the return mark 4 m east of the hero; "all" shows every figure (sought ones too).
const VIEWS := {
	"pradera": [[Vector3(-3.5, 0, -11), "portal"], [Vector3(9, 0, -22.5), ""]],
	"bosque": [[Vector3(-12.5, 0, 9.5), ""]],
	"mina_1": [[Vector3(0, 0, 12), ""], [Vector3(-8, 0, 18), ""], [Vector3(0, 0, 4), ""]],
	"castillo_patio": [[Vector3(0, 0, 18), ""], [Vector3(-7, 0, 17.5), ""],
		[Vector3(24, 0, 6), "all"]],
	"castillo_trono": [[Vector3(0, 0, 10), ""]],
	"caravana": [[Vector3(0, 0, 6), ""], [Vector3(-4.8, 0, -4.5), ""]],
}
const WAIT_FRAMES := 40


func _initialize() -> void:
	_run.call_deferred()


func _run() -> void:
	var args := OS.get_cmdline_user_args()
	var out: String = args[0]
	if args.has("low"):
		Vegetation.half_density = true
		BattleStage.plain_light = true
		ZoneParticles.enabled = false
	ZoneParticles.half = args.has("touch")
	World.debug_no_groups = not args.has("groups")
	DirAccess.make_dir_recursive_absolute(out)
	for zone_id: String in VIEWS:
		for i in (VIEWS[zone_id] as Array).size():
			var view: Array = VIEWS[zone_id][i]
			var world: Node = (load("res://scenes/world/world.tscn") as PackedScene).instantiate()
			world.zone = ZoneData.by_id(zone_id)
			root.add_child(world)
			await process_frame
			world.place_player(view[0])
			world.set_world_flags({"companero": true, "caravana": true})
			if view[1] == "portal":
				world.set_portal(true)
				world.set_return_mark(true, view[0] + Vector3(4, 0, 0))
			if view[1] == "all":
				world.set_quest_view({}, [] as Array[String])
			for f in WAIT_FRAMES:
				await process_frame
			_save(out, "%s_%d" % [zone_id, i])
			world.queue_free()
			await process_frame
	await _battle(out, "mina_1", "combate_mina")
	await _battle(out, "castillo_patio", "combate_castillo")
	quit()


## A battle against a spider on zone's backdrop, waiting for the first command.
func _battle(out: String, zone_id: String, shot: String) -> void:
	var hero := (load("res://data/hero.tres") as Combatant).duplicate(true) as Combatant
	var enemies: Array[Combatant] = [EnemyLibrary.data("arana")]
	var battle: Node = (load("res://scenes/battle/battle_scene.tscn") as PackedScene).instantiate()
	battle.setup(hero, enemies, Inventory.new())
	battle.zone = ZoneData.by_id(zone_id)
	root.add_child(battle)
	for f in WAIT_FRAMES * 2:
		await process_frame
	_save(out, shot)
	battle.queue_free()
	await process_frame


func _save(out: String, shot: String) -> void:
	var calls := Performance.get_monitor(Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME)
	root.get_texture().get_image().save_png(out.path_join(shot + ".png"))
	print("%s: %d llamadas de dibujo" % [shot, calls])
```

## REFILL_GAP or more from the hero and MIN_GAP from every group on the map (taken); null if

static func refill_spot(zone: ZoneData, rng: RandomNumberGenerator, hero_pos: Vector3,
		taken: Array[Vector3]) -> Variant:

func _tick_refill(delta: float) -> void:

			or _player.scripted or _repelled or group_count() >= zone.monster_count:

```glsl
// A flame on a quad that always turns to the camera around its own Y axis (Flame): a
// teardrop torn by noise rising with TIME, white-yellow at the base, orange, red at the tip.
// Unshaded and added on top, it costs nothing on the CPU. Each flame differs by its world
// position. Fog does not dim it.
shader_type spatial;
render_mode unshaded, blend_add, depth_draw_never, cull_disabled, shadows_disabled, fog_disabled;

uniform vec3 base_color : source_color = vec3(1.0, 0.95, 0.65);
uniform vec3 mid_color : source_color = vec3(1.0, 0.55, 0.12);
uniform vec3 tip_color : source_color = vec3(0.85, 0.15, 0.05);
uniform float speed = 1.6;
uniform float strength = 1.3;

varying float seed;

float hash(vec2 p) {
	return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float noise(vec2 p) {
	vec2 i = floor(p);
	vec2 f = fract(p);
	vec2 u = f * f * (3.0 - 2.0 * f);
	return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
		mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

void vertex() {
	// Billboard around Y, keeping the node's scale (Godot's own Y-billboard).
	MODELVIEW_MATRIX = VIEW_MATRIX * mat4(INV_VIEW_MATRIX[0], MODEL_MATRIX[1],
		vec4(normalize(cross(INV_VIEW_MATRIX[0].xyz, MODEL_MATRIX[1].xyz)), 0.0), MODEL_MATRIX[3]);
	MODELVIEW_MATRIX = MODELVIEW_MATRIX * mat4(vec4(length(MODEL_MATRIX[0].xyz), 0.0, 0.0, 0.0),
		vec4(0.0, 1.0, 0.0, 0.0), vec4(0.0, 0.0, length(MODEL_MATRIX[2].xyz), 0.0),
		vec4(0.0, 0.0, 0.0, 1.0));
	seed = fract(dot(NODE_POSITION_WORLD, vec3(0.731, 0.317, 0.513)));
}

void fragment() {
	vec2 p = vec2(UV.x * 2.0 - 1.0, 1.0 - UV.y);  // x -1..1, y 0 at the base, 1 at the tip
	float t = TIME * speed + seed * 10.0;
	float n = noise(vec2(p.x * 3.0, p.y * 4.0 - t * 2.0)) * 0.6
		+ noise(vec2(p.x * 7.0, p.y * 9.0 - t * 3.5)) * 0.4;
	float x = p.x + (n - 0.5) * 0.5 * p.y;  // the top sways more
	float width = mix(0.55, 0.02, pow(p.y, 0.8)) * (0.85 + 0.3 * n);
	float shape = smoothstep(width, width * 0.4, abs(x)) * smoothstep(0.0, 0.08, p.y)
		* (1.0 - smoothstep(0.75 + 0.2 * n, 1.0, p.y));
	vec3 color = mix(base_color, mid_color, smoothstep(0.1, 0.45, p.y));
	color = mix(color, tip_color, smoothstep(0.45, 0.9, p.y));
	ALBEDO = color * shape * strength;
}
```

```glsl
// The swirling surface of the Ala de viaje's portal (TravelPortal), on a quad: a spiral of
// noise turning with TIME, a bright edge and a darker centre, unshaded and added on top.
// ring_only: only the bright edge (the mark on the ground of the spot it leads back to).
shader_type spatial;
render_mode unshaded, blend_add, depth_draw_never, cull_disabled, shadows_disabled, fog_disabled;

uniform vec3 edge_color : source_color = vec3(0.75, 0.9, 1.0);
uniform vec3 swirl_color : source_color = vec3(0.2, 0.45, 1.0);
uniform vec3 core_color : source_color = vec3(0.05, 0.1, 0.35);
uniform float spin = 0.6;
uniform float pulse_time = 1.2;
uniform bool ring_only = false;

float hash(vec2 p) {
	return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float noise(vec2 p) {
	vec2 i = floor(p);
	vec2 f = fract(p);
	vec2 u = f * f * (3.0 - 2.0 * f);
	return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
		mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

void fragment() {
	vec2 p = UV * 2.0 - 1.0;
	float r = length(p);
	if (r > 1.0) {
		discard;
	}
	float pulse = 0.85 + 0.15 * sin(TIME * 6.2831 / pulse_time);
	float edge = smoothstep(0.78, 0.95, r) * (1.0 - smoothstep(0.95, 1.0, r));
	if (ring_only) {
		ALBEDO = edge_color * edge * pulse;
	} else {
		float angle = atan(p.y, p.x) / 6.2831;
		float swirl = noise(vec2(angle * 6.0 + r * 3.0 - TIME * spin, r * 5.0 - TIME * 0.7));
		swirl = smoothstep(0.35, 0.85, swirl);
		vec3 inside = mix(core_color, swirl_color, smoothstep(0.1, 0.8, r));
		vec3 color = inside * (0.5 + 0.8 * swirl) + edge_color * edge * 1.4;
		ALBEDO = color * pulse * (1.0 - smoothstep(0.97, 1.0, r));
	}
}
```
