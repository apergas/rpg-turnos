# Version 3.5.0: combat, companion and portals — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five changes from M-91 to M-95: the hero's damage spells grow 3 % a level above the one that taught them; using an item in battle always acts first; Brena, Tadeo and Ulma wear a new piece of gear at each step of the caravan (seen in battle, a little ATK or DEF); the Barrio del portal's normal battles lose the portal behind the enemies (the Devorador keeps it); the exit-portal between the Caravana and Brumaclara turns reddish. Spec: `docs/boost/specs/2026-11-15-version-3-5-0-design.md`.

**Architecture:** Every rule is pure and small: `Leveling.learned_at()` and `BattleEngine.spell_power()` for the spells, one more command in `BattleEngine._turn_order()`'s front list, `Allies.GEAR` / `Allies.gear()` for the companion's gear (its sums go into the `Combatant`'s existing `equip_attack` / `equip_defense`, which `_roll_damage()` already reads). The companion's look is built by `CharacterBuilder.dress_companion()` (the constructor that already builds the Knight figures); `BattleActor` gets only a 4-line façade, `set_companion_gear()`, because it is a big owner at 740 lines. `BattleStage.build()` takes a `boss` flag; `TravelPortal` takes a `red` flag that `MapProps` sets on `"look": "portal"` exits. The save stays at version 15 with no new fields: the gear comes from `GameState.ally_step()`.

**Tech Stack:** Godot 4.7.2 (Compatibility renderer), GDScript, scenes as text, single-threaded web PWA.

**Assumes the 3.4.0 is merged into `develop`** (spec `docs/boost/specs/2026-11-15-version-3-4-0-design.md`). Interfaces this plan relies on:

```gdscript
## A fresh copy, with its life full: it comes back healed for every battle. A companion
## gets GROWTH once for every tramo after the first (tramo 0 or 1: its own numbers), and the
## ATK and DEF of the gear worn by then (gear()) as its equipment bonuses, which the battle adds
## through total_attack() and total_defense().
static func data(id: String, tramo := 1) -> Combatant:
	var copy := (CREATURES[id].data as Combatant).duplicate() as Combatant
	if is_companion(id):
		var steps := maxi(tramo - 1, 0)
		var growth: Dictionary = GROWTH[id]
		copy.max_hp += growth.max_hp * steps
		copy.attack += growth.attack * steps
		copy.defense += growth.defense * steps
		copy.speed += growth.speed * steps
		var worn := gear(id, tramo)
		copy.equip_attack = worn.attack
		copy.equip_defense = worn.defense
	copy.hp = copy.max_hp
	return copy


## The gear a companion wears at step (GEAR, up to that step): for each piece the Equipment id
## whose tint it wears ("" until its first), and the ATK and DEF they add. {} for a creature.
static func gear(id: String, step: int) -> Dictionary:
	if not is_companion(id):
		return {}
	var worn := {GEAR_WEAPON: "", GEAR_HELMET: "", GEAR_CAPE: "", "attack": 0, "defense": 0}
	var steps: Array = GEAR.keys()
	steps.sort()
	for s: int in steps:
		if s > step:
			break
		var piece: Dictionary = GEAR[s]
		worn[piece.piece] = piece.tint_of
		worn.attack += piece.get("attack", 0)
		worn.defense += piece.get("defense", 0)
	return worn
```
