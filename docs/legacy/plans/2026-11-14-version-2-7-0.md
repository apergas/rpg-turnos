# Versión 2.7.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the Partida nueva +, show the bestiary's cards in three states (unseen, seen, beaten) and make Sanación heal the companion for half, as the spec [2026-11-14-version-2-7-0-design.md](../specs/2026-11-14-version-2-7-0-design.md) says.

**Architecture:** Three independent changes, each one task. Task 1 deletes `NgPlus` and every caller, keeping the save at version 14 (the `ng_plus` field is written as 0 and read but ignored). Task 2 changes only `BestiaryPage._card()` and adds one game token. Task 3 adds `Skill.ally_share` and uses it in `BattleEngine`. Task 4 bumps the version, writes the changelog and runs the full verification.

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer. Godot is run through `.\tools\godot.cmd`.

## The ally's share of a heal the hero casts (Skill.ally_share), up to what it is missing:
## 0 without an ally standing or when it is full.
func _ally_heal(skill: Skill) -> int:
	if skill.ally_share <= 0.0 or not _ally_stands():

	return mini(ceili(skill.power * skill.ally_share), ally.max_hp - ally.hp)
