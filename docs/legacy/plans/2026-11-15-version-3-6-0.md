# Version 3.6.0: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four changes from the spec `docs/boost/specs/2026-11-15-version-3-6-0-design.md`: the creature or companion walks behind the hero on every map (M-96); every village has a tienda (items) and an armero (gear), both buying everything (M-97); the Pluma de fénix is no longer sold, only found in chests and dropped (M-99); the Coleccionista counts 40 medals, gives a ring or an amulet every 4, stands in the Caravana and Brumaclara from the start, and the save goes to version 16 (M-100).

**Architecture:** One new node piece, `MapCompanion` (`scripts/world/map_companion.gd`), owned by `World` like `MapFigures`: World only creates it, calls `step()` in its physics tick and forwards five calls; `Game._refresh_status()` passes it the ally with one line. The shop split is a rule: `Shop.SHOPS` keeps one entry per village and step, and a *counter* (`Shop.ITEMS_COUNTER`, `Shop.ARMORY_COUNTER`) picks which half a figure sells; a new figure kind `"armory"` opens the armory counter. The autoplay's purchases are computed as if one shop sold both halves and then filtered by counter, so the gold is shared exactly as before. The medals are data in `Medals` and `Equipment`; the save gains no field, only `MEDAL_PRIZES_VERSION` (16), from which the prizes count follows the new table. The medal drop chance becomes one per part (`Medals.drop_chance(part)`), tuned in Task 5.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, scenes as text, web PWA single-threaded.

**Assumes (from the 3.4.0 and 3.5.0 plans, executed before this one):**
- 3.4.0 (`docs/boost/specs/2026-11-15-version-3-4-0-design.md`): `ZoneData.npcs` entries may carry `"sign"`, which `MapFigures._figure_sign_text(npc)` returns first (`if npc.has("sign"): return npc.sign`, then `match npc.kind`); the Coleccionista, the Jefe de caravana, Orvalla and the Tablón carry it. `Shop.sellable(state, id)` filters `Shop.sell_list(state)`; `Shop.WORN` is gone; `ShopWindow._add_sell_row()` no longer paints a grey reason. `Allies.stats_text(id, step)`.

## Adaptations to the spec

1. **Each counter has its own keeper's name.** The window's header shows the figure the player talked to, so a `SHOPS` entry gains an optional `"armorer"` (the armero's name) and `"keeper"` becomes the tienda's: Mercader / Armero in Villaclaro, the forest, the castle and the Caravana; Tendera / Herrero in the mine; Tendero / Herrero de cristal in Brumaclara. `Shop.keeper(shop_id, counter)`. The buy page's title, which said «Comprar», says «Tienda» or «Armero» (the spec's "título"); tamers and the Jefe keep «Criaturas» and «Compañeros».
2. **The quest that waits at a shop figure is looked up among the figures of the counter's kind** (`"shop"` for the tienda, `"armory"` for the armero), not among both: the Herrero, now `"armory"`, still hears his quest first, and the new Tendera does not steal it. Today no quest is handed to a shop figure; `QuestLog.problems()` accepts `"armory"` as a figure one can talk to.
3. **The autoplay's purchases are computed once for the whole village shop** (`Shop._autoplay_whole_picks()`, today's body of `autoplay_picks()`) and filtered by counter. Whatever order the tienda and the armero are visited in, the Ala, the gear and the potions bought are the ones bought today. `restock()` visits the tienda and the armero before the Domadora (who waits until the gear is bought).
4. **Autoplay route points.** The walking autoplay buys on its route, so the armero of Villaclaro, the castle and the Caravana each gets one route point; the forest's armero and the mine's tendera sit next to legs the route already walks. Brumaclara's figures are only reached through `restock()`, as the Herrero today.
5. **Looks.** The new figures reuse looks that exist and are not on that map: Villaclaro and castle Armero `SURVIVOR`, forest Armero `TRAVELLER_M`, Caravana Armero `FARMER`, mine Tendera `HEALER`, Brumaclara Tendero `MIST_VILLAGER_M`. No tint and no new `Look` (`actor_looks.gd` is at its budget). Task 2 checks them in frames; if two identical figures stand side by side, swap with another look of this list.
6. **The Pluma de fénix drops** (2 %) go to the most frequent common enemy of each land that has none today: Lobo (forest), Araña (mine), Esqueleto pícaro (castle), Mono aullador (jungle), Cabra montesa (mountain), Sombra (city; all five tie), Fuego fatuo (Ciénaga), Araña de cristal (Cuevas), Caballero de bruma (Ruinas), Ojo de la Niebla (Fuente). The desert already has the Momia (3 %), so it gets none. The castle chest is `castillo_patio_oeste` (on the route).
7. **The prizes' numbers.** Compared with the bestiary families' prizes (v1: Anillo de cristal VEL +2 ATK +2, Amuleto de colmillo VEL +1 ATK +4; v2: Anillo de garra VEL +3 ATK +6, Amuleto del vigía DEF +6 and silence; v3: Anillo de bruma VEL +4 ATK +8, Amuleto de cuarzo DEF +8 and sleep, Amuleto del faro VEL +3 and two statuses), the spec's 20 to 40 were far better than the prizes of their time. This plan keeps the slots, names and statuses and lowers: Anillo de plata ATK +6 (not +8, = Anillo de garra), Anillo de oro ATK +8 (not +14, = Anillo de bruma, reached a part earlier), Amuleto de oro DEF +8 (not +14), Anillo del coleccionista ATK +12 (not +20), Amuleto del coleccionista DEF +12 (not +20). 4 to 16 and 24 stay as the spec says.
8. **The save's migration** ("medal_prizes se pone a 0 antes de validar"): `_valid_medals()` checks the cap only from version 16 (an older count is of the old table) and `apply()` reads `medal_prizes` as 0 below 16. Same result, no write into the Dictionary being validated.
9. **One drop chance per part.** `Medals.DROP_CHANCE` becomes `Medals.DROP_CHANCES` (part → chance) and `Medals.drop_chance(part)`; `BattleFlow` asks it with `GameState.part()` unless the medal tour set its own. Task 5 tunes the three numbers with the formula `target / (2 × common enemies the autoplay beats in that part)` (a player by hand beats about twice as many, as the 2.5.0 tuning assumed), targets 12, 16 and 12.
10. **Orvalla's chapter 14 line** "Y un señor que pregunta por medallas" (he arrived with the Vigía) no longer fits: he is there from the start. It becomes "Y el señor de las medallas dice que por fin ve lo que le traen." (`data/zones/brumaclara.tres:115`).
11. **The medal tour** (`--autoplay-zone=medallas`) keeps `MEDAL_TOUR_CHANCE` 0.25 if it reaches 40 within `MEDAL_TOUR_TIME`; otherwise Task 3 Step 6 raises the chance, then limits the tour to the v1's 12 (the spec's fallback).

```gdscript
## For --autoplay: what a counter buys now. A tamer: its creature (Game chooses a companion).
## A village shop: the picks of the whole shop (_autoplay_whole_picks()) at this counter only,
## the equipment at ARMORY_COUNTER and the rest at ITEMS_COUNTER, so the tienda and the armero
## share the gold as one shop did, in either order.
static func autoplay_picks(state: GameState, shop_id: String, counter: String) -> Array[String]:
	var picks: Array[String] = []
	if sells_ally(shop_id):
		for ally: String in allies_of(shop_id):
			if Allies.is_companion(ally):
				return picks  # Game chooses the companion on autoplay (Task 8), not the shop
			if can_buy(state, ally) and not _gear_pending(state, shop_id):
				picks.append(ally)
		return picks
	for id in _autoplay_whole_picks(state, shop_id):
		if is_equipment(id) == (counter == ARMORY_COUNTER):
			picks.append(id)
	return picks


## One Ala de viaje if none is carried (the autoplay retreat flies back with it), then the
## equipment of the shop that beats what is worn and is not in the bag yet, in slot order, as
## long as the gold lasts. Once there is no such piece left (bought or not), or with no potions
## at all, potions up to AUTOPLAY_POTIONS. In Villaclaro the first 50 G must go on the gear and
## the village is close by, so there the Ala waits until the gear is bought.
static func _autoplay_whole_picks(state: GameState, shop_id: String) -> Array[String]:
	var picks: Array[String] = []
	var gold := state.gold
	var upgrades := 0
	var wants_wing := state.inventory.count(Inventory.WING) == 0
	if wants_wing and shop_id != VILLACLARO and gold >= price(Inventory.WING):
		picks.append(Inventory.WING)
		gold -= price(Inventory.WING)
		wants_wing = false
	for id: String in SHOPS[shop_id].equipment:
		if compare(state, id).diff <= 0 or id in state.bag_equipment:
			continue
		upgrades += 1
		if gold >= price(id):
			picks.append(id)
			gold -= price(id)
	var potion_id := Inventory.BIG_POTION if Inventory.BIG_POTION in SHOPS[shop_id].items \
		else Inventory.POTION
	var potions := state.inventory.count(potion_id)
	if upgrades > 0 and potions > 0:
		return picks
	if upgrades == 0 and wants_wing and gold >= price(Inventory.WING):
		picks.append(Inventory.WING)
		gold -= price(Inventory.WING)
	while potions < AUTOPLAY_POTIONS and gold >= price(potion_id):
		picks.append(potion_id)
		gold -= price(potion_id)
		potions += 1
	return picks
```

```gdscript
class_name MapCompanion extends Node3D
## Node, a piece of World: the creature or the companion that walks behind the hero on the map
## (M-96, 3.6.0). Only a figure: no collider, no prompt, no sign and nothing on the map square,
## so the hero, the monsters and the walls never meet it. It walks GAP metres behind the hero
## along the path he walked (a trail of his positions), stands still when he does and, too far
## behind (SNAP_DISTANCE), appears behind him at once (snap_behind(), also on every placing). It
## hides during cutscenes and while its own figure stands on the map as a character (Brumaclara
## before brumaclara_vista, the ciudad after the Devorador: MapFigures.shows()). A companion
## wears Allies.gear() as in battle (BattleActor.set_companion_gear()), never the hero's rim.
## World creates it, calls step() in its physics tick and passes on set_ally() from
## Game._refresh_status(); never stores World.

const ACTOR_SCENE := preload("res://scenes/battle/battle_actor.tscn")
## Metres behind the hero, along his path.
const GAP := 1.6
## The trail: a point of the hero's path every TRAIL_STEP metres, the newest first,
## TRAIL_POINTS at most (10 m of path).
const TRAIL_STEP := 0.25
const TRAIL_POINTS := 40
## It walks at the hero's speed (Player.SPEED), CATCH_UP times faster while it is more than LAG
## metres from its spot.
const CATCH_UP := 1.5
const LAG := 0.4
## This close to its spot it stands still.
const ARRIVED := 0.05
## Farther than this from the hero (a tight corner, a shortcut), it appears behind him.
const SNAP_DISTANCE := 8.0

var _player: Player
var _figures: MapFigures
## The figure (null: no creature, no companion).
var _actor: BattleActor
var _ally_id := ""
var _gear := {}
## The hero's path, the newest point first (flat: y = 0).
var _trail: Array[Vector3] = []
## Hidden: a cutscene is on, or its own figure stands on the map.
var _in_scene := false
var _figure_shown := false


func setup(player: Player, figures: MapFigures) -> void:
	_player = player
	_figures = figures


func _ready() -> void:
	visible = false


## The creature or companion to show (an Allies id, "" for none) and its growth step
## (GameState.ally_step()): a new one is built and put behind the hero; the same one with
## another step only changes its gear (Allies.gear()).
func set_ally(ally_id: String, step: int) -> void:
	var gear: Dictionary = Allies.gear(ally_id, step) if ally_id != "" else {}
	if ally_id == _ally_id:
		if gear != _gear and _actor != null:
			_actor.set_companion_gear(gear)
		_gear = gear
		return
	_ally_id = ally_id
	_gear = gear
	if _actor != null:
		remove_child(_actor)
		_actor.queue_free()
		_actor = null
	if ally_id != "":
		_actor = ACTOR_SCENE.instantiate()
		_actor.look = EnemyLibrary.look(ally_id)
		add_child(_actor)
		_actor.set_companion_gear(gear)  # a creature ignores it
	refresh()
	snap_behind()


## Hidden while a figure with its name stands on the map (MapFigures.shows()); World calls it
## after every change of the figures shown.
func refresh() -> void:
	_figure_shown = _ally_id != "" and _figures.shows(Allies.display_name(_ally_id))
	_update_visible()


## A cutscene: hidden until end_scene(), which puts it behind the hero where the scene left him.
func begin_scene() -> void:
	_in_scene = true
	_update_visible()


func end_scene() -> void:
	_in_scene = false
	_update_visible()
	snap_behind()


## Behind the hero at once, facing where he faces: the trail starts over, straight behind him.
func snap_behind() -> void:
	_trail.clear()
	if _actor == null:
		return
	var hero := _flat(_player.global_position)
	var yaw := _player.model().rotation.y
	var back := Vector3(sin(yaw), 0.0, cos(yaw))  # the hero's model faces -Z turned by yaw
	for i in ceili(GAP / TRAIL_STEP) + 1:
		_trail.append(hero + back * TRAIL_STEP * i)
	position = _spot() + Vector3(0.0, _player.global_position.y, 0.0)
	_actor.rotation.y = yaw
	_actor.set_walking(false)


## Every physics tick (World, before its own checks, so also while a window holds the map): a
## point of the trail every TRAIL_STEP metres the hero walks, and a step toward the spot GAP
## metres behind him; the walk cycle while it moves, the idle one once there.
func step(delta: float) -> void:
	if not visible:
		return
	if _trail.is_empty():
		snap_behind()
		return
	var hero := _flat(_player.global_position)
	if hero.distance_to(_trail[0]) >= TRAIL_STEP:
		_trail.push_front(hero)
		if _trail.size() > TRAIL_POINTS:
			_trail.pop_back()
	var here := _flat(position)
	if here.distance_to(hero) > SNAP_DISTANCE:
		snap_behind()
		return
	var to_spot := _spot() - here
	var walking := to_spot.length() > ARRIVED
	if walking:
		var speed := Player.SPEED * (CATCH_UP if to_spot.length() > LAG else 1.0)
		position = here + to_spot.limit_length(speed * delta) \
			+ Vector3(0.0, _player.global_position.y, 0.0)
		var target_yaw := atan2(-to_spot.x, -to_spot.z)  # the model faces -Z
		_actor.rotation.y = lerp_angle(_actor.rotation.y, target_yaw,
			minf(1.0, Player.TURN_SPEED * delta))
	_actor.set_walking(walking)


## The point GAP metres behind the hero along his trail (its last point if it is shorter).
func _spot() -> Vector3:
	var left := GAP
	var from := _flat(_player.global_position)
	for point in _trail:
		var d := from.distance_to(point)
		if d >= left:
			return from.move_toward(point, left)
		left -= d
		from = point
	return from


## Shown only with a figure, out of cutscenes and with its own figure off the map; coming back
## into view it appears behind the hero.
func _update_visible() -> void:
	var shown := _actor != null and not _in_scene and not _figure_shown
	if shown and not visible:
		visible = true
		snap_behind()
	visible = shown


static func _flat(v: Vector3) -> Vector3:
	return Vector3(v.x, 0.0, v.z)
```
