# Arreglos de QA sobre la 1.1.0: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolver los hallazgos de QA que el usuario aprobó: que no se pierda una partida sin aviso, que la interfaz quepa y se pueda tocar en el móvil, que el jugador sepa qué hacer y dónde comprar, y que una versión nueva llegue a quien ya tiene el juego.

**Architecture:** Cambios pequeños en la interfaz y en las reglas puras que ya existen. Solo hay una clase nueva, `WebUpdate`, que aísla el JavaScript del service worker. La fuente es `docs/boost/qa/2026-11-06-qa-multiplataforma.md` en la rama `feature/qa-docs` (los `QAM-nn` de este plan son los suyos).

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Global Constraints

- Sin tests de ningún tipo. Se verifica a mano: `--check-only`, partidas, capturas. Los scripts de prueba van fuera del repositorio.
- Mensajes de commit en inglés, sin ninguna atribución ni trailer.
- Rama `feature/qa-1-1`, creada sobre `feature/evolutivos-1-1`. Sin push, merge ni tags.
- Nunca tocar `docs/boost/estado-proyecto.md`.
- Toda ejecución de Godot que pueda escribir en `user://` lleva `APPDATA` redirigido a una carpeta del scratchpad: la partida real del usuario no se toca. La excepción es exportar la web, que necesita las plantillas del `APPDATA` real y no escribe partidas.
- El juego está solo en castellano.
- Las reglas viven en clases puras, sin autoloads, escenas de texto.
- Medidas del móvil: 740 × 360 en ventana real (`--resolution 740x360 ... -- --touch`). `--write-movie` ignora `--resolution`: para capturar a ese tamaño hay que guardar `root.get_texture().get_image()` desde un script. La pantalla virtual mide unos 1096 × 533 con textos normales y 925 × 450 con "Textos grandes".
- Cada tarea actualiza las líneas de `CLAUDE.md` de lo que cambia.
- **Fuera de este plan, a propósito:** `viewport-fit=cover` (QAM-13). Sin un iPhone real no se puede comprobar, y puede meter los controles bajo la muesca. Se queda el nombre corto del icono.

const FIGURE_SIGN_COLOR := Color(1.0, 0.95, 0.8)

## What a figure offers, over its head: its model alone doesn't tell.
static func _figure_sign_text(npc: Dictionary) -> String:
	match npc.kind:
		"shop":
			return "Criaturas" if Shop.sells_ally(npc.id) else "Tienda"
		"inn":
			return "Posada"
	return ""


func _add_figure_sign(npc: Dictionary) -> void:
	var text := _figure_sign_text(npc)
	if text == "":
		return
	var label := Label3D.new()
	label.text = text
	label.font_size = 40
	label.pixel_size = 0.01
	label.outline_size = 10

	(_figures[npc.name] as Node3D).add_child(label)
	_figure_signs.append(label)

```gdscript
class_name WebUpdate extends RefCounted
## A new deploy of the web build: its service worker installs and waits until every tab is
## closed, so a player can stay on the old version for good. This notices one waiting and
## tells it to take over, which reloads the page. Off the web it does nothing.

const FLAG := "window.villaclaroUpdate"
const WATCH_JS := """
window.villaclaroUpdate = false;
if ('serviceWorker' in navigator) {
	navigator.serviceWorker.getRegistration().then(function (reg) {
		if (!reg) { return; }
		var mark = function () { if (reg.waiting) { window.villaclaroUpdate = true; } };
		mark();
		reg.addEventListener('updatefound', function () {
			if (reg.installing) { reg.installing.addEventListener('statechange', mark); }
		});
		reg.update();
	});
}
"""
const APPLY_JS := """
navigator.serviceWorker.getRegistration().then(function (reg) {
	if (reg && reg.waiting) { reg.waiting.postMessage('update'); }
});
"""


static func watch() -> void:
	if OS.has_feature("web"):
		JavaScriptBridge.eval(WATCH_JS, true)


static func is_ready() -> bool:
	return OS.has_feature("web") and JavaScriptBridge.eval(FLAG + " === true", true) == true


static func apply() -> void:
	if OS.has_feature("web"):
		JavaScriptBridge.eval(APPLY_JS, true)
```
