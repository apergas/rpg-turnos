> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five interface touches with no new game rules (M-86 to M-90): the «Vender» page lists only what can be sold, «Equipo» puts each piece's effect in small text under its name, «Estado» shows the companion's or creature's numbers, the battle menu turns grey while a target is chosen (desktop), and the Coleccionista, the Jefe de caravana, Orvalla and the Tablón get a name sign over their heads. No new script, no new `class_name`, no new token; `game.gd`, `world.gd` and `battle_actor.gd` are not touched.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, scenes as text, single-threaded web PWA.

## Adaptations to the spec

Read the code; these decisions refine the spec where it is silent or where the code makes a step unnecessary:

1. **The Tablón of the mine (`mina_1`) gets its sign too.** The spec's table lists the Tablón in "Villaclaro, bosque, castillo, Caravana y Brumaclara", but `data/zones/mina_1.tres` also has one (`"name": "Tablón"`, line 88), and the Coleccionista next to it is in the table. Leaving one board without its sign would be inconsistent; all six boards get it.
2. **`_back()` from the target page needs no saved state.** It already calls `_open(_target_back, _target_back_cursor)`, which rebuilds every row from `_engine.problem()`: a «Huir» grey against a boss and a spell with no MP come back grey on their own. The plan only adds a comment; nothing is stored in `_ask_target()`.
3. **A click on a grey row does nothing** (it doesn't go back). Grey rows let clicks through (`_set_enabled()`), so today such a click would land in `_unhandled_input()` and count as "a click anywhere else". The target page now ignores clicks inside the command window, like the spell and item lists already do for their grey rows. A click off the window still goes back.
4. **`Shop.WORN` is deleted.** Once the list holds only sellable rows, its only use is `sell_problem()`, whose result `sell()` only shows for a row that can no longer exist. `sell_problem()` keeps the safety net with `NOT_CARRIED` («No lo llevas») for "none to sell".
5. **`Shop.sellable(state, id)` takes no shop.** `sell_price()` depends on the shop only for prize rings and amulets, which always pay at least `PRIZE_ACCESSORY_MIN` (10 G), so "price over 0" is the same in every shop.
6. **The Equipo page on a phone already scrolls** (`_build_equipment()` wraps `_equip_box` in a `ScrollBox` when `Device.is_touch()`). Task 2 only checks the desktop page fits in 1280 × 720; if it doesn't, the same `ScrollBox` is used on desktop too (Step 4 of Task 2 has the code).
7. **The Criaturas and Compañeros rows of the shop** now read «PV · ATK · DEF · VEL» too (Task 3), because they share `Allies.stats_text()`. The CHANGELOG says so.

```gdscript
## What can be sold now, in list order: the equipment in the bag in catalog order (one row per
## id; what is worn is not listed) and the items carried, each only while sellable().
static func sell_list(state: GameState) -> Array[String]:
	var ids: Array[String] = []
	for id: String in Equipment.EQUIPMENT:
		if sellable(state, id):
			ids.append(id)
	for id in Inventory.IDS:
		if sellable(state, id):
			ids.append(id)
	return ids


## True while state carries a copy of id to sell (the worn one does not count) and a shop pays
## something for it: not the prizes with no price, the quest items or the seeds. The shop never
## matters here: a prize ring or amulet pays PRIZE_ACCESSORY_MIN at least anywhere.
static func sellable(state: GameState, id: String) -> bool:
	return sell_count(state, id) > 0 and sell_price(id) > 0
```

```gdscript
## Why id can't be sold ("" if it can): none to sell (the worn one does not count), or not for
## sale. sell_list() lists only what can be, so this is sell()'s safety net.
static func sell_problem(state: GameState, id: String, shop_id := "") -> String:
	if sell_count(state, id) <= 0:
		return NOT_CARRIED
	if sell_price(id, shop_id) <= 0:
		return NOT_FOR_SALE
	return ""
```
