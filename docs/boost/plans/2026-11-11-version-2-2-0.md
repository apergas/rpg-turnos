# Versión 2.2.0: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** La tercera zona de la v2: la montaña. Dos plantas de celdas al aire libre (`montana_1` "La subida", con una palanca que abre la reja de la escalera, y `montana_2` "La cumbre", con el Grifo en una explanada), roca gris con nieve encima, suelo de nieve y piedra, pinos; cinco enemigos nuevos y el Grifo de la cumbre; el equipo de adamantita en la tienda de la Caravana (tramo 3); la Sanación (Nv 32); dos misiones (`cabras` y `cristales_hielo`); el fondo de combate `montana`, la música, el viento y la nieve. Spec: `docs/boost/specs/2026-11-10-version-2-0-0-design.md` (M-43 a M-46, la montaña; "Versiones", fila 2.2.0; "Partida automática"; "Verificación"). Lo que ese spec dejó abierto lo fija `docs/boost/specs/2026-11-11-version-2-2-0-design.md`.

**Architecture:** Casi todo es dato sobre las reglas de la 2.1.0. Lo nuevo en código: `ZoneData.rock_piece` y `DungeonMap` dibuja cada bloque de roca con una pieza de Kenney (el acantilado nevado) y, en una planta al aire libre, el suelo de fuera y los picos (`hills`); `NatureModels` / `Decor` ganan las piezas de la montaña; `BattleEngine` gana el estado `stun` (el golpe de la Cabra hace perder el turno); `BattleActor` gana seis figuras; `BattleStage` el fondo `montana`; `StoryState` los objetivos de la montaña por planta; `Game` gana `--autoplay-zone=montana`.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Global Constraints

- **Sin tests de ningún tipo, nunca.** Nada de TDD, ni carpeta `tests/`, ni frameworks (GUT, gdUnit4), ni pasos de "escribe un test que falle". Se verifica a mano: `--check-only` en cada script cambiado, `--import` después de añadir un `class_name` o modelos, partidas automáticas (`-- --autoplay`, `--autoplay-zone=...`), la salida de Godot, y fotos o fotogramas (`--write-movie`, o un script del scratchpad que guarda `root.get_texture().get_image()`). Los scripts de comprobación viven en el scratchpad, nunca en el repositorio.
- **Godot solo a través de `C:\Users\peixe\Documents\rpg-turnos\tools\godot.cmd`.** **Toda** ejecución (también `--import`, `--check-only` y los scripts del scratchpad) lleva `APPDATA` redirigido **en el mismo comando** a una carpeta literal del scratchpad, desde Git Bash: `APPDATA='<scratchpad>\impl\appdata' ./tools/godot.cmd ...`. `<scratchpad>` es siempre la ruta literal y completa del scratchpad de la sesión que implementa (por ejemplo `C:\Users\peixe\AppData\Local\Temp\rpg-scratch`): se escribe entera en cada orden. La única excepción es exportar la web (Task 11), que necesita las plantillas del `APPDATA` real y no escribe partidas.
- Juego **solo en castellano** (textos, avisos `push_warning`, líneas `Depuración: ...`). Comentarios de código y documentos en el estilo del repositorio (comentarios `##` en inglés, documentos en castellano).
- Escenas como texto: los `.tscn` solo tienen la raíz y su script; todo lo demás se construye en código. Las reglas en clases puras (`RefCounted` / `Resource`) que no tocan nodos. Sin autoloads.

## Coordenadas de las plantas

Una planta de 15 × 13 celdas de 4 m: el centro de la celda (x, y) está en `((x − 7) × 4, 0, (y − 6) × 4)`, de x −28 a 28 y de z −24 (norte) a 24 (sur), como en la mina (`half_size` 30 × 26). Las dos plantas están comprobadas con un BFS: con la reja cerrada, la sala de la escalera de la planta 1 es lo único inalcanzable; con ella abierta, todo; la planta 2 se recorre entera. Las rutas de la partida automática de las Tasks 2 y 8 pasan solo por celdas de suelo, sin cortar esquinas de roca.

```gdscript
extends SceneTree
## Photos of world maps (the hero placed at each VIEWS point, the map camera on him) and of
## battle backdrops, with the draw calls of each one. No monster groups, no particles.
## godot --path <repo> --resolution 1280x720 --script <this> -- <out dir> [nodecor] [low]
## "nodecor": the mountain floors without their decoration (the draw-call baseline).
## "low": the low quality flags (half the soft decoration, plain light).

const VIEWS := {
	"pradera": [Vector3(0, 0, -16)],
	"jungla": [Vector3(0, 0, 36)],
	"desierto": [Vector3(-14, 0, 8)],
	"caravana": [Vector3(0, 0, 6)],
	"mina_1": [Vector3(0, 0, 12), Vector3(-4, 0, -4)],
	"castillo_patio": [Vector3(0, 0, 16), Vector3(12, 0, 0)],
	"montana_1": [Vector3(0, 0, 18.5), Vector3(4, 0, 4), Vector3(-20, 0, -6),
		Vector3(12, 0, -16)],
	"montana_2": [Vector3(0, 0, 16), Vector3(-16, 0, -2), Vector3(0, 0, -12),
		Vector3(20, 0, 8)],
}
## Zone ids whose battle backdrop is photographed ("combate_<backdrop>").
const BACKDROPS := ["pradera", "desierto", "mina_1", "castillo_patio", "montana_1"]
const WAIT_FRAMES := 40


func _initialize() -> void:
	_run.call_deferred()


func _run() -> void:
	var args := OS.get_cmdline_user_args()
	var out: String = args[0]
	var nodecor := args.has("nodecor")
	if args.has("low"):
		Vegetation.half_density = true
		BattleStage.plain_light = true
	ZoneParticles.enabled = false
	DirAccess.make_dir_recursive_absolute(out)
	for zone_id: String in VIEWS:
		if not zone_id in ZoneData.IDS:
			continue  # the mountain before Task 2
		var points: Array = VIEWS[zone_id]
		for i in points.size():
			_forget_caches()
			var zone := ZoneData.by_id(zone_id).duplicate() as ZoneData
			zone.monster_count = 0
			if nodecor and zone_id.begins_with("montana"):
				zone.decor = []
			var world: Node = (load("res://scenes/world/world.tscn") as PackedScene).instantiate()
			world.zone = zone
			root.add_child(world)
			await process_frame
			world.place_player(points[i])
			for f in WAIT_FRAMES:
				await process_frame
			_save(out, "%s_%d" % [zone_id, i])
			world.queue_free()
			await process_frame
	for zone_id: String in BACKDROPS:
		if not zone_id in ZoneData.IDS:
			continue
		var zone := ZoneData.by_id(zone_id)
		var stage := Node3D.new()
		root.add_child(stage)
		BattleStage.build(stage, zone)
		var camera := Camera3D.new()
		camera.fov = BattleScene.CAMERA_FOV
		stage.add_child(camera)
		camera.position = BattleScene.CAMERA_POS
		camera.look_at(BattleScene.ENEMY_POS.lerp(BattleScene.HERO_POS, 0.35) + Vector3(0, 0.8, 0))
		camera.current = true
		for f in WAIT_FRAMES:
			await process_frame
		_save(out, "combate_%s" % zone.backdrop)
		stage.queue_free()
		await process_frame
	quit()


## The per-zone caches of Decor and WorldStage key on the zone id: a copy of a zone with other
## decoration must not reuse them.
func _forget_caches() -> void:
	Decor._placed_zone = ""
	Decor._scatter_zone = ""
	Decor._placed_grid_zone = ""
	Decor._solid_grid_zone = ""
	WorldStage._layout_zone = ""
	WorldStage._tree_zone = ""
	WorldStage._chest_zone = ""


func _save(out: String, shot: String) -> void:
	var calls := Performance.get_monitor(Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME)
	root.get_texture().get_image().save_png(out.path_join(shot + ".png"))
	print("%s: %d llamadas de dibujo" % [shot, calls])
```

(`BattleScene.CAMERA_FOV`, `CAMERA_POS`, `ENEMY_POS` y `HERO_POS` son constantes de `scripts/battle/battle_scene.gd`. Si una caché estática de `Decor` o `WorldStage` tiene otro nombre, búscala por `static var _` y ajústala.)

```gdscript
extends SceneTree
## Puts <before>/<x>.png and <after>/<x>.png side by side in <out>/<x>.png (left: before).
## godot --headless --path <repo> --script <this> -- <before> <after> <out>


func _initialize() -> void:
	var args := OS.get_cmdline_user_args()
	DirAccess.make_dir_recursive_absolute(args[2])
	for file in DirAccess.get_files_at(args[1]):
		if not file.ends_with(".png") or not FileAccess.file_exists(args[0].path_join(file)):
			continue
		var before := Image.load_from_file(args[0].path_join(file))
		var after := Image.load_from_file(args[1].path_join(file))
		var both := Image.create(before.get_width() + after.get_width(),
			maxi(before.get_height(), after.get_height()), false, before.get_format())
		both.blit_rect(before, Rect2i(Vector2i.ZERO, before.get_size()), Vector2i.ZERO)
		after.convert(before.get_format())
		both.blit_rect(after, Rect2i(Vector2i.ZERO, after.get_size()), Vector2i(before.get_width(), 0))
		both.save_png(args[2].path_join(file))
	quit()
```

```gdscript
	var size := zone.grid_size()
	var box := BoxMesh.new()
	box.size = Vector3(ZoneData.CELL, WALL_HEIGHT, ZoneData.CELL)
	var piece := _rock_piece_mesh()
	# The piece is a unit cube: each block scales it to the cell (the box already is).
	var block_scale := box.size if piece else Vector3.ONE
	var body := StaticBody3D.new()
	add_child(body)
	var buried: Array[Transform3D] = []
	for y in size.y:
		for x in size.x:
			var cell := Vector2i(x, y)
			if zone.cell_char(cell) != ZoneData.ROCK:
				continue
			var pos := zone.cell_center(cell) + Vector3(0, WALL_HEIGHT / 2.0, 0)
			if not _touches_floor(cell):
				buried.append(Transform3D(Basis.from_scale(block_scale), pos))
				continue
			var mi := MeshInstance3D.new()
			mi.mesh = piece if piece else box
			mi.scale = block_scale
			mi.material_override = _rock_materials[_shade(cell)]
			mi.position = pos
			add_child(mi)
			_blocks[cell] = mi
			var shape := CollisionShape3D.new()
			shape.shape = BoxShape3D.new()
			(shape.shape as BoxShape3D).size = box.size
			shape.position = pos
			body.add_child(shape)
	if piece:
		LowPoly.add_multimesh(self, piece, buried, _rock_materials[0])
	else:
		var buried_mesh := box.duplicate() as BoxMesh
		buried_mesh.material = _rock_materials[0]
		LowPoly.add_multimesh(self, buried_mesh, buried)
```

```gdscript
## The mountain: a strong wind that never stops. A low roar (noise low-passed twice at
## 250 Hz) under a howling band that wanders between 350 and 800 Hz, both swelling in long
## gusts that never fall below a third.
static func _mountain_wind(count: int, rng: RandomNumberGenerator) -> PackedFloat32Array:
	var out := PackedFloat32Array()
	out.resize(count)
	var low_a := _pole(250.0)
	var l1 := 0.0
	var l2 := 0.0
	var band := PackedFloat32Array()
	var x1 := 0.0
	var x2 := 0.0
	var y1 := 0.0
	var y2 := 0.0
	for i in count:
		var t := float(i) / MusicLibrary.RATE
		if i % 32 == 0:
			band = _band(560.0 + 220.0 * sin(TAU * 0.07 * t) + 90.0 * sin(TAU * 0.31 * t + 1.0),
				10.0)
		var x := rng.randf_range(-1.0, 1.0)
		var y := band[0] * x + band[1] * x2 - band[2] * y1 - band[3] * y2
		x2 = x1
		x1 = x
		y2 = y1
		y1 = y
		l1 += low_a * (x - l1)
		l2 += low_a * (l1 - l2)
		var gust := 0.35 + 0.65 * pow(0.5 + 0.5 * sin(TAU * 0.125 * t), 1.5)
		out[i] = (2.5 * y + 2.0 * l2) * gust
	return out


## A howl of the wind over the peaks: 2 to 3.5 s of noise through a narrow band that rises
## from 500 Hz to its top and falls back, swelling and dying away.
static func _howl(rng: RandomNumberGenerator) -> PackedFloat32Array:
	var count := int(rng.randf_range(2.0, 3.5) * MusicLibrary.RATE)
	var top := rng.randf_range(950.0, 1300.0)
	var out := PackedFloat32Array()
	out.resize(count)
	var band := PackedFloat32Array()
	var x1 := 0.0
	var x2 := 0.0
	var y1 := 0.0
	var y2 := 0.0
	for i in count:
		var u := float(i) / count
		if i % 32 == 0:
			band = _band(lerpf(500.0, top, sin(PI * u)), 20.0)
		var x := rng.randf_range(-1.0, 1.0)
		var y := band[0] * x + band[1] * x2 - band[2] * y1 - band[3] * y2
		x2 = x1
		x1 = x
		y2 = y1
		y1 = y
		out[i] = y * pow(sin(PI * u), 1.2)
	return out
```
