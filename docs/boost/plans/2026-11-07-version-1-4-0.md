# Versión 1.4.0, el Eco de la Niebla: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cubrir M-22 de `docs/boost/documento-maestro.md`. Tras los créditos, en el salón del trono (`castillo_trono`) espera el **Eco de la Niebla**, un jefe opcional que se puede repetir. La primera victoria da la **Corona de bruma**, un accesorio con ATK +5 y DEF +5.

**Architecture:** El Eco es un enemigo más (`data/enemies/eco_niebla.tres`) con un campo nuevo de `Combatant`, `reward_equipment`, que da una pieza la primera vez que se vence. `ZoneData` gana `postgame_boss_id`: con la partida terminada, ese jefe ocupa el sitio del jefe de la zona. `World` recibe qué jefe debe dibujar (`boss_id`) y espera a que el héroe se aleje tras un combate de jefe, para que el Eco no vuelva a atacar en cuanto se termina el combate. `Equipment` y `Loadout` aceptan accesorios que dan ATK y DEF. La primera victoria queda guardada en la bandera `eco_niebla` de `world_flags`, y la Corona va en el equipo, que ya se guarda. Por eso **el guardado no cambia de versión**.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto.

## Global Constraints

- El juego está solo en castellano. Las reglas van en clases puras (`RefCounted` / `Resource`) sin nodos. Las escenas se escriben como texto con solo la raíz. Sin autoloads.
- Mensajes de commit en inglés, sin atribución ni trailer de ningún tipo.
- Gitflow: rama `feature/version-1-4-0` creada desde `develop`, un commit por tarea y merge `--no-ff` a `develop` al final. Sin push ni tags.
- Cada tarea actualiza en `CLAUDE.md` las líneas de lo que cambia.
- En el móvil la pantalla virtual mide unos 1096 × 533 (925 × 450 con "Textos grandes"). Se comprueba con `--resolution 740x360 ... -- --touch`. Todo lo que se toque debe caber ahí y tener botones de dedo (`UiStyle.fit_finger()`).

## Valores del Eco y objetivo de equilibrio

Objetivo: a nivel 20, con el equipo de platino (casco incluido) y el Esqueleto leal, ganar entre un 60 % y un 75 % de las veces, con la partida automática eligiendo las órdenes (`BattleAutoplay`). También debe ser claramente más duro que el Señor de la Niebla, al que la partida automática gana un 88 % de las veces a nivel 17 y un 95 % a nivel 20, con el mismo equipo y la misma criatura.

| Campo | Valor |
|---|---|
| PV / PM | 550 / 60 |
| ATK / DEF / VEL | 70 / 46 / 18 |
| `ai_weights` | `attack` 50, `charge` 25, `niebla` 25 |
| Hechizo | `niebla.tres` (a todos, 30 de daño, 30 % de Silencio), el mismo que el Señor en su segunda fase |
| Resiste | `thunder` (el Rayo del héroe hace la mitad) |
| EXP / oro | 600 / 500 |
| Premio | `corona_bruma`, solo la primera vez |

Simulación hecha con el `BattleEngine` y el `BattleAutoplay` reales, 2000 combates por fila. El héroe lleva 5 Pociones y 3 Éteres, Normal salvo donde se indica:

| Caso | Victorias |
|---|---|
| Nv 20, platino + casco, Esqueleto leal | **66 %** (13 rondas de media) |
| Nv 20, platino + casco, sin criatura | 48 % |
| Nv 20, sin casco, Esqueleto leal | 59 % |
| Nv 19, sin casco, Esqueleto leal | 52 % |
| Nv 18, sin casco, Esqueleto leal | 43 % |
| Nv 20 con la Corona (revancha), Esqueleto leal / sin criatura | 76 % / 58 % |
| Fácil, Nv 20, Esqueleto leal / sin criatura | 96 % / 89 % |

Con 700 PV y ATK 80 bajaba al 18 %, y con 500 PV subía al 72 %. Una persona juega mejor que `BattleAutoplay`, que no se defiende antes del golpe cargado si no es su turno, así que las cifras reales serán algo más altas. La partida automática completa termina hoy en Nv 18-19: el Eco pide entrenar uno o dos niveles después de los créditos, y eso es lo que se buscaba. El script para repetir la simulación está en la Tarea 2, paso 7.

```gdscript
extends SceneTree
## Eco de la Niebla balance: the real BattleEngine and BattleAutoplay, N battles a case.

const N := 2000


func _initialize() -> void:
	_report("Nv 20, platino, Esqueleto leal", 20, true, "esqueleto_leal", false)
	_report("Nv 20, platino, sin criatura", 20, true, "", false)
	_report("Nv 20, con Corona, Esqueleto leal", 20, true, "esqueleto_leal", true)
	_report("Nv 18, sin casco, Esqueleto leal", 18, false, "esqueleto_leal", false)
	quit()


func _hero(level: int, helmet: bool, crown: bool) -> GameState:
	var st := GameState.new(load("res://data/hero.tres"))
	st.hero.experience = Leveling.EXP_TABLE[level - 1]
	Leveling.apply(st.hero)
	st.heal_full()
	var gear := ["espada_platino", "armadura_platino", "escudo_platino"]
	if helmet:
		gear.append("casco_platino")
	if crown:
		gear.append(Equipment.MIST_CROWN)
	for id: String in gear:
		st.bag_equipment.append(id)
		st.equip(id)
	st.inventory.add(Inventory.POTION, 2)  # 5 in all
	st.inventory.add(Inventory.ETHER, 3)
	return st


func _report(label: String, level: int, helmet: bool, ally: String, crown: bool) -> void:
	var wins := 0
	var rounds := 0
	for i in N:
		var st := _hero(level, helmet, crown)
		var rng := RandomNumberGenerator.new()
		rng.seed = i * 7919 + 13
		var enemies: Array[Combatant] = [EnemyLibrary.data("eco_niebla").duplicate(true)]
		var engine := BattleEngine.new(st.hero, enemies, rng, st.inventory)
		if ally != "":
			engine.ally = Allies.data(ally)
		var pilot := BattleAutoplay.new()
		var n := 0
		while engine.state == BattleEngine.State.ONGOING and n < 200:
			engine.resolve_round(pilot.choose(engine))
			n += 1
		rounds += n
		if engine.state == BattleEngine.State.WON:
			wins += 1
	print("%-36s %5.1f %%  (%.1f rondas)" % [label, 100.0 * wins / N, float(rounds) / N])
```
