# Versión 1.2.0, orientación y comodidad: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el jugador sepa siempre dónde está y qué le toca hacer (sobre todo en la mina), y que volver por zonas ya superadas, curarse y empezar en el móvil cueste menos: M-07 a M-17 de `docs/boost/documento-maestro.md`.

**Architecture:** Cambios pequeños sobre lo que ya existe. Hay una clase pura nueva, `MapMarks` (`scripts/world/map_marks.gd`), que saca de `World` las marcas del mapa para que las dibujen igual el mapa pequeño y la página "Mapa" de la pausa. Las reglas nuevas van a clases puras que ya existen: `EncounterMeter` (la regla de los encuentros a la mitad), `StoryState` (el objetivo de la mina), `QuestLog` (el progreso en las frases de espera), `GameState` (Incienso y hechizos fuera de combate) y `SaveData` (la línea de la partida en el título). Las escenas solo enseñan sus resultados.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Global Constraints

- **Sin tests de ningún tipo, nunca.** Nada de TDD, ni carpeta `tests/`, ni pasos de "escribe un test que falle". Se verifica a mano: `.\tools\godot.cmd --headless --path . --check-only --script res://...`, partidas automáticas (`-- --autoplay`, `--autoplay-zone=...`), capturas, y scripts de prueba fuera del repositorio, en el scratchpad (un `SceneTree` lanzado con `--script <ruta absoluta>`).
- Toda ejecución de Godot que pueda escribir en `user://` lleva `APPDATA` redirigido a una carpeta del scratchpad (`$env:APPDATA = '<scratchpad>\appdata'` antes de llamar a `tools\godot.cmd`): la partida real del usuario no se toca. La excepción es exportar la web, que necesita las plantillas del `APPDATA` real.
- Juego solo en castellano. Reglas en clases puras (`RefCounted` / `Resource`) sin nodos, escenas como texto con solo la raíz, sin autoloads.
- Mensajes de commit en inglés, sin atribución ni trailer de ningún tipo (ni `Co-Authored-By`, ni "Generated with").
- Gitflow: rama `feature/version-1-2-0` creada desde `develop` (con la 1.1.1 ya integrada), un commit por tarea, merge `--no-ff` a `develop` al final. Sin push ni tags.
- Cada tarea actualiza las líneas de `CLAUDE.md` de lo que cambia.
- En el móvil la pantalla virtual mide unos 1096 × 533 (925 × 450 con "Textos grandes"); se comprueba con `.\tools\godot.cmd --path . --resolution 740x360 -- --touch`. `--write-movie` ignora `--resolution`: para capturar a ese tamaño se guarda `get_tree().root.get_texture().get_image()` desde un script. Todo lo que se toque debe caber ahí y tener botones de dedo (`UiStyle.fit_finger()`).
- Guardado: sigue en la versión 9. Este plan no añade nada al guardado (el Incienso se guarda como un objeto más del inventario; los metros que le quedan no, ver "Fuera de este plan").
- No se toca `docs/boost/qa/brief-qa-agentes.md` en ningún paso.
- **Se ejecuta después de la 1.1.1.** Varias tareas tocan archivos que la 1.1.1 también cambia (`battle_hud.gd`, `pause_menu.gd`, `title_screen.gd`, `quest_log.gd`, `save_data.gd`, `game.gd`). Cada paso dice qué función toca: parte de cómo esté el archivo al empezar, no de las líneas que cita este plan, y no deshagas nada de la 1.1.1.

```gdscript
class_name MapMarks extends RefCounted
## The points of interest of a zone on its map (the map square and the pause menu's Mapa
## page), each a small square of its kind's color: shops, inns, wells (grey while dry),
## exits and, on a dungeon floor, the stairs up and down, the lever, the gates and the key.
## The lever and the gates change color once used; the key goes once taken. Pure: World and
## PauseMenu draw them.

const SHOP := "shop"
const INN := "inn"
const WELL_HP := "well_hp"
const WELL_MP := "well_mp"
const WELL_DRY := "well_dry"
const EXIT := "exit"
const STAIRS_UP := "stairs_up"
const STAIRS_DOWN := "stairs_down"
const LEVER := "lever"
const LEVER_DOWN := "lever_down"
const DOOR := "door"
const DOOR_OPEN := "door_open"
const KEY := "key"
## Every kind, in the order of the Mapa page's legend.
const KINDS: Array[String] = [SHOP, INN, WELL_HP, WELL_MP, WELL_DRY, EXIT, STAIRS_UP,
	STAIRS_DOWN, LEVER, LEVER_DOWN, DOOR, DOOR_OPEN, KEY]
const COLORS := {
	SHOP: Color(1.0, 0.8, 0.2),
	INN: Color(1.0, 0.6, 0.85),
	WELL_HP: Color(1.0, 0.25, 0.25),
	WELL_MP: Color(0.25, 0.5, 1.0),
	WELL_DRY: Color(0.55, 0.55, 0.55),
	EXIT: Color(0.35, 1.0, 0.45),
	STAIRS_UP: Color(0.3, 0.95, 1.0),
	STAIRS_DOWN: Color(0.7, 0.4, 1.0),
	LEVER: Color(1.0, 0.55, 0.1),
	LEVER_DOWN: Color(0.45, 0.3, 0.15),
	DOOR: Color(0.6, 0.0, 0.0),
	DOOR_OPEN: Color(0.4, 0.4, 0.5),
	KEY: Color(1.0, 1.0, 0.55),
}
const NAMES := {
	SHOP: "Tienda",
	INN: "Posada",
	WELL_HP: "Pozo de vida",
	WELL_MP: "Pozo de maná",
	WELL_DRY: "Pozo seco",
	EXIT: "Salida",
	STAIRS_UP: "Escalera de subida",
	STAIRS_DOWN: "Escalera de bajada",
	LEVER: "Palanca",
	LEVER_DOWN: "Palanca bajada",
	DOOR: "Reja cerrada",
	DOOR_OPEN: "Reja abierta",
	KEY: "Llave",
}


## Every mark of zone now, with the world flags and the dry wells:
## [{"pos": Vector3, "kind": String, "color": Color}].
static func of_zone(zone: ZoneData, flags: Dictionary, dry_wells: Array[String]) -> Array[Dictionary]:
	var marks: Array[Dictionary] = []
	for npc: Dictionary in zone.npcs:
		if npc.kind == "shop":
			_add(marks, npc.pos, SHOP)
		elif npc.kind == "inn":
			_add(marks, npc.pos, INN)
	for well: Dictionary in zone.wells:
		var kind := WELL_HP if well.kind == Wells.HP else WELL_MP
		_add(marks, well.pos, WELL_DRY if dry_wells.has(well.id) else kind)
	for exit: Dictionary in zone.all_exits():
		var kind := EXIT
		if exit.get("stairs", false):
			kind = STAIRS_UP if exit.id == ZoneData.STAIRS_UP else STAIRS_DOWN
		_add(marks, exit.pos, kind)
	if not zone.is_dungeon():
		return marks
	if zone.lever_flag != "":
		var down: bool = flags.get(zone.lever_flag, false)
		for cell in zone.find_cells(ZoneData.LEVER):
			_add(marks, zone.cell_center(cell), LEVER_DOWN if down else LEVER)
	if zone.door_flag != "":
		var open: bool = flags.get(zone.door_flag, false)
		for cell in zone.find_cells(ZoneData.DOOR):
			_add(marks, zone.cell_center(cell), DOOR_OPEN if open else DOOR)
	if zone.floor_key != "" and not flags.get(zone.floor_key, false):
		for cell in zone.find_cells(ZoneData.KEY):
			_add(marks, zone.cell_center(cell), KEY)
	return marks


## The marks whose cell has been seen on map (the rest are not shown, nor in the legend).
static func seen(marks: Array[Dictionary], map: ExploredMap) -> Array[Dictionary]:
	var shown: Array[Dictionary] = []
	for mark in marks:
		var cell := Vector2i(map.grid_point(mark.pos)).clamp(Vector2i.ZERO, map.size - Vector2i.ONE)
		if map.is_seen(cell):
			shown.append(mark)
	return shown


## The kinds among marks, in KINDS order (the Mapa page's legend).
static func kinds_in(marks: Array[Dictionary]) -> Array[String]:
	var kinds: Array[String] = []
	for kind in KINDS:
		for mark in marks:
			if mark.kind == kind:
				kinds.append(kind)
				break
	return kinds


static func _add(marks: Array[Dictionary], pos: Vector3, kind: String) -> void:
	marks.append({"pos": pos, "kind": kind, "color": COLORS[kind]})
```

func spell_problem(skill: Skill) -> String:

func cast_spell(skill: Skill) -> int:
	if spell_problem(skill) != "":

	return amount

## Fuera de este plan

- **Los metros del Incienso no se guardan.** Guardarlos obligaría a subir la versión del guardado (10) por 200 m de efecto. Al cargar una partida, el Incienso encendido se ha acabado; el objeto sin usar sí se guarda, como cualquier otro.
- **La regla de los encuentros en el castillo.** Su nivel de salida es 17 y el máximo es 20, así que nunca llega a la mitad. Es la última zona, y el documento pide la regla para las zonas ya superadas.
- **Varias ranuras (M-20).** La línea bajo "Continuar" es la única de la 1.2.0; la 1.3.0 la pasa a cada ranura con `SaveData.summary_line()`.
- **Hechizos de ataque en la pausa.** M-13 pide Curar y Curar+; Ascuas, Llamarada y Rayo no tienen uso fuera de combate y no salen en la página.
- **`docs/boost/qa/brief-qa-agentes.md`.** No se actualiza en este plan, por decisión del usuario.
