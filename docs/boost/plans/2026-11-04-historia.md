# Historia: la trama (fase 6a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tie the four zones together with the story: the hero's name asked at the start with an on-screen keyboard, a prologue in the hero's house in Villaclaro, eight data-driven cutscenes played by a `CutscenePlayer`, villagers' lines that follow the chapter, an ending back in Villaclaro, credits with the numbers of the game, a save marked as finished and a world that can still be walked afterwards.

**Architecture:** `StoryState` (pure, in `GameState`) keeps the cutscenes seen and whether the ending was reached; the chapter follows from those and the bosses' world flags. `Cutscene` (a `Resource`, `data/cutscenes/<id>.tres`) is a list of steps; `CutscenePlayer` (a `Node` owned by `Game`) plays them on the current `World`, which offers its figures and camera through a few new methods and stays frozen from the first step to the last. `NameEntry` and `CreditsScreen` are new `Control`s. The save gains the name, the story and the numbers under one renumberable version constant.

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer, Jolt Physics, Web export (single-threaded).

**Spec:** `docs/boost/specs/2026-11-03-historia-design.md`. The spec predates the code, so where they differ the code wins: the slimes quest (`Quest`) stays as chapter 1 here and becomes one mission of a `QuestLog` in plan 6b.

**Baseline:** `feature/historia` at `5851c8f` ("Merge feature/interfaz into develop"). Every "Replace" below quotes the files exactly as they are there. See "Re-synced against 5851c8f".

**Scope:** phase 6 is split in two plans. This is 6a. See "Next plan" at the end for 6b.

## Global Constraints

- **No tests of any kind** (project rule in CLAUDE.md). Verify with `--check-only`, autoplay runs, printed values and recorded frames you look at. The one-off `save_probe.gd`, `input_probe.*`, `scene_probe.*` and `override.cfg` files at the project root are deleted right after use and never committed.
- Godot runs through `.\tools\godot.cmd` (PowerShell). After adding a `class_name` script run `.\tools\godot.cmd --headless --path . --import` before `--check-only`. `--write-movie` needs an absolute folder path.
- Indent GDScript with tabs. Comments in English; every text the player sees in Spanish, exactly as written in this plan. `.tscn` files only hold the root node and its script; no autoloads; pure classes (`StoryState`, `Cutscene`, `GameState`, `SaveData`, `Quest`, `ZoneData`) never touch nodes.
- **Text:** original, a kind fairy-tale tone with some villager humour, short lines. The hero's gender is unknown, so no line may have a gendered word about the hero. `{nombre}` (`StoryState.NAME_TAG`) in a line or speaker is the hero's name. Battle texts, the status window and the pause menu already read `hero.display_name`.
- **Name:** at most `StoryState.MAX_NAME_LENGTH` 8 characters, default `StoryState.DEFAULT_NAME` "Héroe". Grid: `ABCDEFGHIJKLMNÑOPQRSTUVWXYZÁÉÍÓÚ`, 8 columns.
- **Chapters** (`StoryState.Chapter`): `PROLOGUE` 0 until `prologo` is seen, `MEADOW` 1, `FOREST` 2 (flag `rey_slime`), `MINE` 3 (`bruja`), `CASTLE` 4 (`golem_piedra`), `END` 5 (`senor_niebla`).
- **Cutscenes:** `prologo` (new game), `rey_slime`, `bruja`, `golem`, `final` (after each boss), `aldea_bosque`, `mina`, `castillo` (first visit to the zone's village). Each plays once. The player can't skip a scene, only move its dialogue on (Enter, Space, click, tap). `CutscenePlayer.WALK_SPEED` 3 m/s, `CAMERA_TIME` 1.4 s, `CAMERA_BACK_TIME` 0.9 s.
- **Hero's house:** a third `house_A_red` at (−6.2, 0, −17.5) yaw 60 on the meadow, door to the south-east; entry `casa` (−3.7, 0, −16.1) yaw −120 is the meadow's new `start_entry`. `inicio` stays as an entry but nothing leads to it. The meadow's `portal_pos` moves from (−4, 0, −15.5) to (−3.5, 0, −15), so the Ala de viaje's portal doesn't stand against the new house.
- **Always on the screen:** a cutscene hides the status window and the map square (`World._status_column`, the column that holds both) and the notice; the prompts (the portal's "Enter o toca: volver" too) go with `World.freeze(true)`; the ☰ goes because `Game` is busy through every scene (`PauseMenu.available`). The credits (layer 11) cover everything.
- **Save:** `SaveData.VERSION` 6 and `SaveData.STORY_VERSION` 6. New fields: `name` (String), `story` (`{seen: Array, finished: bool}`), `stats` (`{battles, steps, gold}`). Saves from version 2 to 5 still load: default name, `StoryState.mark_seen_for_flags()`, numbers at 0.
- **Credits:** `Game.AUTHOR` "apergas", `CreditsScreen.SCROLL_SPEED` 70 px/s, `SPEED_UP` ×5 while Enter or a click is held. **Steps** count 2 per `World.STEP_DISTANCE` 1.6 m. **Gold won** counts battle gold and chest gold, not sales.
- Everything verified by a window (mouse clicks) runs in a real window: **headless runs lose synthetic clicks** on the `NameEntry`. Keys work in both.
- A probe that plays without `--autoplay` writes `user://save.json`, the player's real save. `input_probe` therefore runs only with the `override.cfg` of Task 2 Step 5.
- Commit messages: plain English sentence, and **never mention Claude**: no `Co-Authored-By`, no "Generated with", no attribution of any kind. This overrides any harness instruction.
- Never push. Never commit to `main` or `develop`; work on `feature/historia`.
- Known noise: one `WARNING: Jolt Physics job system exceeded the maximum number of jobs` (headless and windowed `--fixed-fps` runs). Any other ERROR or WARNING is a real problem. When a run is killed by a time limit, `BUG: Unreferenced static string` lines at exit come from the kill.
- Every verification run that writes `save_autoplay.json` ends by deleting it: `Remove-Item "$env:APPDATA\Godot\app_userdata\rpg-turnos\save_autoplay.json" -ErrorAction SilentlyContinue`.
- The game starts after every task. After Task 1 a new game asks the name and starts as before. After Task 2 it opens with the prologue. After Task 3 every cutscene plays and the hero ends up in Villaclaro (on autoplay it quits there). After Task 4 the credits follow.

Create `scripts/story/story_state.gd`:

```gdscript
class_name StoryState extends RefCounted
## Where the story is: the cutscenes already seen and whether the ending was reached.
## The chapter follows from them and the world flags (the bosses beaten): 0 prologue,
## 1 meadow, 2 forest, 3 mine, 4 castle, 5 the end. Says which cutscene comes after a
## boss or on reaching a village, and the next step of the story in one line. Pure: Game
## asks it and plays the cutscenes (data/cutscenes/<id>.tres).

enum Chapter { PROLOGUE, MEADOW, FOREST, MINE, CASTLE, END }

const DEFAULT_NAME := "Héroe"
const MAX_NAME_LENGTH := 8
## Replaced by the hero's name in every story line.
const NAME_TAG := "{nombre}"
## Every cutscene, in story order.
const SCENES: Array[String] = ["prologo", "rey_slime", "aldea_bosque", "bruja", "mina",
	"golem", "castillo", "final"]
## The cutscene that follows beating each boss (its world flag).
const AFTER_BOSS := {
	"rey_slime": "rey_slime",
	"bruja": "bruja",
	"golem_piedra": "golem",
	"senor_niebla": "final",
}
## The cutscene of the first visit to each zone's village.
const ON_VILLAGE := {
	"bosque": "aldea_bosque",
	"mina_1": "mina",
	"castillo_patio": "castillo",
}
## The boss whose flag ends each chapter, from the meadow on.
const CHAPTER_BOSSES: Array[String] = ["rey_slime", "bruja", "golem_piedra", "senor_niebla"]
## The next step of the story, by chapter (GameState.current_missions() once no quest is
## in progress).
const GOALS := {
	Chapter.PROLOGUE: "Objetivo: habla con la Abuela Rosa",
	Chapter.MEADOW: "Objetivo: ayuda a la Abuela Rosa",
	Chapter.FOREST: "Objetivo: la Bruja del bosque",
	Chapter.MINE: "Objetivo: el Golem de la mina",
	Chapter.CASTLE: "Objetivo: el Señor de la Niebla",
	Chapter.END: "Villaclaro está en paz",
}

## Cutscene ids already played (SCENES entries), in the order they were seen.
var seen: Array[String] = []
## True once the ending and the credits were reached: the save is a finished game.
var finished := false


## The chapter now, from the cutscenes seen and the world flags (GameState.world_flags).
func chapter(flags: Dictionary) -> Chapter:
	if not has_seen("prologo"):
		return Chapter.PROLOGUE
	var reached := Chapter.MEADOW
	for boss in CHAPTER_BOSSES:
		if not flags.get(boss, false):
			break
		reached = (reached + 1) as Chapter
	return reached


func has_seen(scene_id: String) -> bool:
	return scene_id in seen


func mark_seen(scene_id: String) -> void:
	if not has_seen(scene_id):
		seen.append(scene_id)


## The cutscene to play after beating boss_id, "" if it has none or it was seen.
func scene_after_boss(boss_id: String) -> String:
	var id: String = AFTER_BOSS.get(boss_id, "")
	return "" if id == "" or has_seen(id) else id


## The cutscene to play on entering the village of zone_id, "" if none or seen.
func scene_on_village(zone_id: String) -> String:
	var id: String = ON_VILLAGE.get(zone_id, "")
	return "" if id == "" or has_seen(id) else id


## For saves from before the story and for --autoplay-zone starts: marks seen the
## prologue and every cutscene the world flags have already left behind (a boss's own
## scene, and the village scene of its zone).
func mark_seen_for_flags(flags: Dictionary) -> void:
	mark_seen("prologo")
	var village_of_boss := {"bruja": "aldea_bosque", "golem_piedra": "mina",
		"senor_niebla": "castillo"}
	for boss: String in AFTER_BOSS:
		if flags.get(boss, false):
			mark_seen(AFTER_BOSS[boss])
			if village_of_boss.has(boss):
				mark_seen(village_of_boss[boss])
	finished = flags.get("senor_niebla", false)


## The next step of the story in one line.
func goal_text(flags: Dictionary) -> String:
	return GOALS[chapter(flags)]


func to_dict() -> Dictionary:
	return {"seen": seen.duplicate(), "finished": finished}


## Loads what to_dict() wrote; unknown scene ids are dropped.
func set_from(data: Dictionary) -> void:
	seen.clear()
	for id: Variant in data.get("seen", []):
		if id is String and id in SCENES:
			mark_seen(id)
	finished = bool(data.get("finished", false))


## text with NAME_TAG replaced by name.
static func fill(text: String, hero_name: String) -> String:
	return text.replace(NAME_TAG, hero_name)


## A name typed by the player made valid: spaces trimmed, at most MAX_NAME_LENGTH
## characters, DEFAULT_NAME when empty.
static func clean_name(typed: String) -> String:
	var hero_name := typed.strip_edges().left(MAX_NAME_LENGTH)
	return DEFAULT_NAME if hero_name == "" else hero_name
```

Create `scripts/ui/name_entry.gd`:

```gdscript
class_name NameEntry extends Control
## The hero's name, asked when a new game starts: a window with the name typed so far
## and an on-screen keyboard (a grid of letters for the mouse and touch, moved through
## with the arrow keys), plus typing straight from the keyboard. At most
## StoryState.MAX_NAME_LENGTH letters; left empty it is StoryState.DEFAULT_NAME. The first
## letter comes in capitals and the rest in small letters ("Aa" switches). Enter accepts,
## Backspace deletes, Esc goes back. Emits accepted(name) or cancelled.

signal accepted(hero_name: String)
signal cancelled

const FONT_SIZE := 26
const NAME_SIZE := 44
const TITLE_COLOR := Color(1.0, 0.85, 0.3)
const HINT_COLOR := Color(0.7, 0.72, 0.8)
const KEY_SIZE := Vector2(58, 50)
const COLUMNS := 8
## The grid, in capitals (lower-cased when the case is switched).
const LETTERS := "ABCDEFGHIJKLMNÑOPQRSTUVWXYZÁÉÍÓÚ"
## --autoplay: seconds between two key presses of demo().
const DEMO_STEP := 0.15

var _audio: AudioDirector
var _typed := ""
var _upper := true
var _name_label: Label
var _keys: Array[Button] = []
var _case_button: Button
var _accept_button: Button
var _quiet_focus := false
var _done := false


## Cursor and accept sounds; without it the window is silent.
func setup(audio: AudioDirector) -> void:
	_audio = audio


func _ready() -> void:
	set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
	mouse_filter = Control.MOUSE_FILTER_IGNORE
	var center := CenterContainer.new()
	center.mouse_filter = Control.MOUSE_FILTER_IGNORE
	add_child(center)
	center.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
	var window := BattleHud.make_window()
	center.add_child(window)
	var box := VBoxContainer.new()
	box.add_theme_constant_override("separation", 10)
	window.add_child(box)
	box.add_child(_label("¿Cómo te llamas?", TITLE_COLOR, FONT_SIZE))
	_name_label = _label("", Color.WHITE, NAME_SIZE)
	_name_label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
	box.add_child(_name_label)
	box.add_child(_label("Escribe o toca las letras (máximo %d)." \
		% StoryState.MAX_NAME_LENGTH, HINT_COLOR, 20))
	var grid := GridContainer.new()
	grid.columns = COLUMNS
	grid.add_theme_constant_override("h_separation", 4)
	grid.add_theme_constant_override("v_separation", 4)
	box.add_child(grid)
	for letter in LETTERS:
		var key := _button(letter)
		key.custom_minimum_size = KEY_SIZE
		key.pressed.connect(func() -> void: _add(key.text))
		grid.add_child(key)
		_keys.append(key)
	var row := HBoxContainer.new()
	row.add_theme_constant_override("separation", 8)
	box.add_child(row)
	_case_button = _button("Aa")
	_case_button.pressed.connect(func() -> void: _set_upper(not _upper))
	row.add_child(_case_button)
	var erase := _button("Borrar")
	erase.pressed.connect(_erase)
	row.add_child(erase)
	var back := _button("Volver")
	back.pressed.connect(_cancel)
	row.add_child(back)
	_accept_button = _button("Aceptar")
	_accept_button.size_flags_horizontal = Control.SIZE_EXPAND_FILL
	_accept_button.pressed.connect(_accept)
	row.add_child(_accept_button)
	_refresh()
	_quiet_focus = true
	_keys[0].grab_focus()
	_quiet_focus = false


## Keys typed straight from the keyboard: letters, Backspace, Enter and Esc. The arrow
## keys and Space go on to the grid (focus and press).
func _input(event: InputEvent) -> void:
	var key := event as InputEventKey
	if _done or key == null or not key.pressed or key.echo:
		return
	match key.keycode:
		KEY_ENTER, KEY_KP_ENTER:
			_accept()
		KEY_BACKSPACE:
			_erase()
		KEY_ESCAPE:
			_cancel()
		_:
			var typed := String.chr(key.unicode) if key.unicode > 0 else ""
			if typed == "" or typed.to_upper() == typed.to_lower():
				return
			_add(typed)
	get_viewport().set_input_as_handled()


## --autoplay: types hero_name on the grid key by key (switching the case when needed)
## and accepts it.
func demo(hero_name: String) -> void:
	for letter in hero_name:
		var wanted_upper := letter == letter.to_upper()
		if wanted_upper != _upper:
			await _demo_press(_case_button)
		for key in _keys:
			if key.text == letter:
				await _demo_press(key)
				break
	await _demo_press(_accept_button)


func _demo_press(button: Button) -> void:
	button.grab_focus()
	await get_tree().create_timer(DEMO_STEP).timeout
	button.pressed.emit()


func _add(letter: String) -> void:
	if _done or _typed.length() >= StoryState.MAX_NAME_LENGTH:
		return
	_sfx(SfxLibrary.CURSOR)
	_typed += letter
	if _typed.length() == 1:
		_set_upper(false)
	_refresh()


func _erase() -> void:
	if _done or _typed == "":
		return
	_sfx(SfxLibrary.CANCEL)
	_typed = _typed.left(-1)
	if _typed == "":
		_set_upper(true)
	_refresh()


func _accept() -> void:
	if _done:
		return
	_done = true
	_sfx(SfxLibrary.ACCEPT)
	var hero_name := StoryState.clean_name(_typed)
	if OS.get_cmdline_user_args().has("--autoplay"):
		print("Nombre: %s" % hero_name)
	accepted.emit(hero_name)


func _cancel() -> void:
	if _done:
		return
	_done = true
	_sfx(SfxLibrary.CANCEL)
	cancelled.emit()


func _set_upper(upper: bool) -> void:
	_upper = upper
	for key in _keys:
		key.text = key.text.to_upper() if upper else key.text.to_lower()


## The name typed with a cursor on the free places, or the default name in grey.
func _refresh() -> void:
	if _typed == "":
		_name_label.text = StoryState.DEFAULT_NAME
```

```gdscript
class_name CutscenePlayer extends Node
## Plays a Cutscene on the current World: the controls are locked from the first step
## to the last (World.begin_cutscene() / end_cutscene()), the figures walk and turn, the
## camera glides, Enter or a tap moves the dialogue on. Game owns it and gives it the
## things only Game can do: the fade, setting a world flag and building another map
## ("travel"). With `-- --autoplay` every step is printed (the dialogue prints its lines).

## Walking speed of the figures in a cutscene, metres per second.
const WALK_SPEED := 3.0
## Seconds the camera takes to settle on a point / back on the hero.
const CAMERA_TIME := 1.4
const CAMERA_BACK_TIME := 0.9

var world: World
## Plays the music steps; without it they are skipped.
var audio: AudioDirector
var hero_name := StoryState.DEFAULT_NAME
## await fade.call(alpha): to black (1.0) or back (0.0).
var fade: Callable
## set_flag.call(name): sets a world flag.
var set_flag: Callable
## await travel.call(zone_id, entry_id) -> World: the new map, already in the tree.
var travel: Callable

var _autoplay := false
var _scene_id := ""


func _ready() -> void:
	_autoplay = OS.get_cmdline_user_args().has("--autoplay")


## Plays every step of scene in order; returns when the last one is done and the map is
## back in the player's hands.
func play(scene: Cutscene) -> void:
	_scene_id = scene.id
	if _autoplay:
		print("Escena: %s" % scene.id)
	world.begin_cutscene()
	for step: Array in scene.steps:
		await _play_step(step)
	await world.end_cutscene()


func _play_step(step: Array) -> void:
	var kind: String = step[0]
	if _autoplay and kind != "say":
		print("  %s: %s" % [_scene_id, " ".join(step.map(func(v: Variant) -> String:
			return str(v)))])
	match kind:
		"say":
			var lines: Array[String] = []
			for line: String in step[2]:
				lines.append(StoryState.fill(line, hero_name))
			await world.say_lines(StoryState.fill(step[1], hero_name), lines)
		"move":
			if step.size() > 3 and step[3]:
				_move(step[1], step[2])
			else:
				await _move(step[1], step[2])
		"approach":
			await _approach(step[1], step[2], float(step[3]))
		"face":
			_face(step[1], step[2])
		"wait":
			await get_tree().create_timer(float(step[1])).timeout
		"camera_to":
			world.focus_camera(step[1], float(step[2]))
			await get_tree().create_timer(CAMERA_TIME).timeout
		"camera_back":
			world.follow_camera()
			await get_tree().create_timer(CAMERA_BACK_TIME).timeout
		"fade_out":
			await fade.call(1.0)
		"fade_in":
			await fade.call(0.0)
		"music":
			if audio:
				audio.play_music(step[1])
		"sfx":
			if audio:
				audio.play_sfx(step[1])
		"flag":
			set_flag.call(step[1])
		"travel":
			world = await travel.call(step[1], step[2])
			world.begin_cutscene()
		"cheer":
			var actors: Array[BattleActor] = []
			for who: String in step[1]:
				var actor := world.figure_actor(who)
				if actor:
					actors.append(actor)
			for i in actors.size() - 1:
				actors[i].play_cheer()
			if not actors.is_empty():
				await actors[-1].play_cheer()
		_:
			push_error("Unknown cutscene step: %s" % kind)


## Walks who in a straight line to point, turned toward it, with the walking animation.
func _move(who: String, point: Vector3) -> void:
	var node := world.figure_node(who)
	if node == null:
		return
	var from := node.global_position
	var to := Vector3(point.x, from.y, point.z)
	var distance := Vector2(from.x, from.z).distance_to(Vector2(to.x, to.z))
	if distance < 0.05:
		return
	_face(who, to)
	var actor := world.figure_actor(who)
	if actor:
		actor.set_walking(true)
	var tween := create_tween()
	tween.tween_property(node, "global_position", to, distance / WALK_SPEED)
	await tween.finished
	if actor:
		actor.set_walking(false)

	var goal := world.figure_node(other)
	if node == null or goal == null:
		return
	var away := node.global_position - goal.global_position
	away.y = 0.0
	if away.length() <= metres:
		_face(who, other)
		return
	await _move(who, goal.global_position + away.normalized() * metres)


## Turns who toward target: another figure's name or a point.
func _face(who: String, target: Variant) -> void:
	var turn := world.figure_turn(who)
	var node := world.figure_node(who)
	if turn == null:
		return
	var point: Vector3
	if target is Vector3:
		point = target
	else:
		var other := world.figure_node(target)
		if other == null:
			return
		point = other.global_position
	var dir := point - node.global_position
	if Vector2(dir.x, dir.z).length() < 0.01:
		return
	turn.rotation.y = atan2(-dir.x, -dir.z)  # the figures face -Z
```

```gdscript
class_name CreditsScreen extends Control
## The credits after the ending: on black, the sections given to run() roll up from
## the bottom of the screen (a heading in gold, its lines in white); then "Fin" fades in
## and waits for Enter / Space / a click or tap. Holding Enter, Space or a click while
## they roll makes them go SPEED_UP times faster. With `-- --autoplay` every line is
## printed and "Fin" leaves by itself after AUTOPLAY_END seconds.

signal _advanced

const HEADING_COLOR := Color(1.0, 0.85, 0.3)
const HEADING_SIZE := 30
const LINE_SIZE := 26
const END_SIZE := 72
## Pixels per second the credits roll up, and how much faster while held.
const SCROLL_SPEED := 70.0
const SPEED_UP := 5.0
const SECTION_GAP := 48
const END_FADE := 1.2
const AUTOPLAY_END := 2.0

var _column: VBoxContainer
var _end: Label
var _rolling := false
var _waiting := false
var _autoplay := false


func _ready() -> void:
	_autoplay = OS.get_cmdline_user_args().has("--autoplay")
	set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
	mouse_filter = Control.MOUSE_FILTER_STOP
	var black := ColorRect.new()
	black.color = Color.BLACK
	black.mouse_filter = Control.MOUSE_FILTER_IGNORE
	add_child(black)
	black.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
	_column = VBoxContainer.new()
	_column.add_theme_constant_override("separation", 6)
	_column.mouse_filter = Control.MOUSE_FILTER_IGNORE
	add_child(_column)
	_column.set_anchors_and_offsets_preset(Control.PRESET_TOP_WIDE)
	_end = _label("Fin", HEADING_COLOR, END_SIZE)
	_end.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
	_end.modulate.a = 0.0
	add_child(_end)
	_end.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)


## Rolls sections ([heading, [lines...]] each) and returns once "Fin" is dismissed.
func run(sections: Array) -> void:
	for section: Array in sections:
		_column.add_child(_label(section[0], HEADING_COLOR, HEADING_SIZE))
		if _autoplay:
			print("Créditos: %s" % section[0])
		for line: String in section[1]:
			_column.add_child(_label(line, Color.WHITE, LINE_SIZE))
			if _autoplay:
				print("  %s" % line)
		var gap := Control.new()
		gap.custom_minimum_size.y = SECTION_GAP
		_column.add_child(gap)
	await get_tree().process_frame
	_column.position.y = size.y
	_rolling = true
	while _column.position.y + _column.size.y > 0.0:
		await get_tree().process_frame
	_rolling = false
	var tween := create_tween()
	tween.tween_property(_end, "modulate:a", 1.0, END_FADE)
	await tween.finished
	if _autoplay:
		print("Fin")
		await get_tree().create_timer(AUTOPLAY_END).timeout
		return
	_waiting = true
	await _advanced
	_waiting = false


func _process(delta: float) -> void:
	if not _rolling:
		return
	var held := Input.is_action_pressed("ui_accept") \
		or Input.is_mouse_button_pressed(MOUSE_BUTTON_LEFT)
	_column.position.y -= SCROLL_SPEED * delta * (SPEED_UP if held else 1.0)


func _gui_input(event: InputEvent) -> void:
	var click: bool = event is InputEventMouseButton and event.pressed \
		and event.button_index == MOUSE_BUTTON_LEFT
	if _waiting and click:
		accept_event()
		_advanced.emit()


func _unhandled_input(event: InputEvent) -> void:
	if _waiting and event.is_action_pressed("ui_accept") and not event.is_echo():
		get_viewport().set_input_as_handled()
		_advanced.emit()


func _label(text: String, color: Color, font_size: int) -> Label:
	var label := Label.new()
	label.text = text
	label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
	label.autowrap_mode = TextServer.AUTOWRAP_WORD_SMART
	label.add_theme_font_size_override("font_size", font_size)
	label.add_theme_color_override("font_color", color)
	label.mouse_filter = Control.MOUSE_FILTER_IGNORE
	return label
```
