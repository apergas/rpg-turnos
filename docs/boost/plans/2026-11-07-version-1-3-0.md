# Versión 1.3.0, colección y partidas: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cubrir M-18 a M-21 del documento maestro: un apartado "Colección" en el Diario, fichas del bestiario con los enemigos vencidos, tres ranuras de partida y exportar o importar una ranura con un archivo.

**Architecture:** Las reglas nuevas van en clases puras: `GameState.defeated_enemies`, `SaveData` (versión 10, `summary_line()`, `from_json()`), `EnemyLibrary.zone_names()`, `BestiaryPage.entry_lines()`, `JournalPage.collection_lines()`. `SaveStore` pasa a trabajar por ranura. Hay dos clases nuevas de interfaz: `SlotList` (la lista de ranuras del título, con sus páginas de confirmación y de acciones) y `SaveTransfer` (un `Node` que aísla la descarga, el `<input type=file>` de la web y el `FileDialog` de escritorio, como `WebUpdate` aísla el service worker).

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

**Orden:** se ejecuta después de la 1.1.1 (M-01 a M-06, M-23 a M-25) y de la 1.2.0 (M-07 a M-17). El plan está escrito contra el código de `develop` de hoy. Donde un paso depende de lo que esas versiones hayan cambiado (sobre todo M-16 en el título, M-02 en la migración del bestiario y M-07 en los nombres de zona), el paso lo dice: parte de cómo esté el archivo y conserva lo que ellas añadieron.

## Global Constraints

- **Sin tests de ningún tipo, nunca.** Nada de TDD, ni carpeta `tests/`, ni pasos de "escribe un test que falle". Se verifica a mano: `.\tools\godot.cmd --headless --path . --check-only --script res://...`, partidas automáticas (`-- --autoplay`, `--autoplay-zone=...`), capturas, y scripts de prueba fuera del repositorio, en el scratchpad.
- Toda ejecución de Godot que pueda escribir en `user://` lleva `APPDATA` redirigido a una carpeta del scratchpad (en PowerShell, `$env:APPDATA = "<scratchpad>\appdata"` antes de llamar a `tools\godot.cmd`): la partida real del usuario no se toca. La excepción es exportar la web, que necesita las plantillas del `APPDATA` real y no escribe partidas.
- Juego solo en castellano. Reglas en clases puras (`RefCounted` / `Resource`) sin nodos, escenas como texto con solo la raíz, sin autoloads.
- Mensajes de commit en inglés, sin atribución ni trailer de ningún tipo.
- Gitflow: rama `feature/version-1-3-0` creada desde `develop`, un commit por tarea, merge `--no-ff` a `develop` al final. Sin push ni tags.
- Cada tarea actualiza las líneas de `CLAUDE.md` de lo que cambia.
- En el móvil la pantalla virtual mide unos 1096 × 533 (925 × 450 con "Textos grandes"); se comprueba con `.\tools\godot.cmd --path . --resolution 740x360 -- --touch`. Todo lo que se toque debe caber ahí y tener botones de dedo (`UiStyle.fit_finger()`). `--write-movie` ignora `--resolution`: para capturar a ese tamaño, guarda `get_tree().root.get_texture().get_image()` desde un script.
- Guardado: hoy es la versión 9. Este plan la sube a **10** (Tarea 1, los enemigos vencidos). Un guardado anterior debe seguir cargando.
- Las ejecuciones `--autoplay` siguen usando `user://save_autoplay.json` y nunca tocan las ranuras.
- Nunca tocar `docs/boost/estado-proyecto.md` ni `docs/boost/qa/brief-qa-agentes.md`.

**Fuera de este plan:**

- Comprobar en un iPhone y en un Android reales la descarga y la subida del archivo. Sin aparatos no se puede: la Tarea 4 lo deja escrito como pendiente para el usuario.
- Recordar la última ranura jugada para poner el foco en ella. Pediría otro dato en el guardado o en las opciones, y con tres ranuras no hace falta: el foco va a la primera ranura que se puede elegir.

- [ ] **Step 4: `EnemyLibrary.zone_names()`.**

```gdscript
## Where enemy_id lives: the names of the zones whose encounters, rare enemy or boss bring
## it, each once, in ZoneData.IDS order ("La mina" once for its three floors).
static func zone_names(enemy_id: String) -> Array[String]:
	var names: Array[String] = []
	for zone_id in ZoneData.IDS:
		var zone := ZoneData.by_id(zone_id)
		if not _lives_in(zone, enemy_id):
			continue
		var place := zone.display_name.left(1).to_upper() + zone.display_name.substr(1)
		if not names.has(place):
			names.append(place)
	return names


static func _lives_in(zone: ZoneData, enemy_id: String) -> bool:
	if zone.boss_id == enemy_id or zone.rare_enemy == enemy_id:
		return true
	for formation: Array in zone.formations + zone.start_formations:
		if formation.has(enemy_id):
			return true
	return false
```

```gdscript
## How many enemies of ORDER have been seen.
static func seen_count(state: GameState) -> int:
	var seen := 0
	for id in ORDER:
		if state.seen_enemies.has(id):
			seen += 1
	return seen


static func count_text(state: GameState) -> String:
	return "Bestiario %d/%d" % [seen_count(state), ORDER.size()]


## Back from a card: the focus goes to it again.
func focus_card(id: String) -> void:
	var card: Button = _cards.get(id)
	if card != null and not card.disabled:
		card.grab_focus()


## The lines of enemy id's card: where it lives, what hurts it more or less, and whether it
## has been beaten. Only reads state.
static func entry_lines(id: String, state: GameState) -> Array[String]:
	var enemy := EnemyLibrary.data(id)
	var places := EnemyLibrary.zone_names(id)
	return [
		"Vive en: %s" % (", ".join(places) if not places.is_empty() else "?"),
		"Débil a: %s" % _elements(enemy.weak),
		"Resiste: %s" % _elements(enemy.resist),
		"Vencido" if state.defeated_enemies.has(id) else "Aún no vencido",
	]


static func _elements(ids: Array[String]) -> String:
	if ids.is_empty():
		return "nada"
	var names: Array[String] = []
	for element in ids:
		names.append(ELEMENT_NAMES.get(element, element))
	return ", ".join(names)
```

- [ ] **Step 1: `SaveStore` por ranuras.** Sustituye las constantes y las tres funciones de la partida:

```gdscript
## Number of save slots on the title screen.
const SLOT_COUNT := 3
## Slot n's file (n from 1 to SLOT_COUNT).
const SLOT_PATH := "user://save_%d.json"
## The single save of 1.2 and older: migrate_legacy() moves it to slot 1.
const LEGACY_SAVE_PATH := "user://save.json"
const AUTOPLAY_SAVE_PATH := "user://save_autoplay.json"
const OPTIONS_PATH := "user://options.json"

## What a slot holds.
enum SlotKind { EMPTY, DAMAGED, USABLE }


## The file of slot (autoplay runs always use their own, whatever the slot).
static func save_path(slot: int) -> String:
	if OS.get_cmdline_user_args().has("--autoplay"):
		return AUTOPLAY_SAVE_PATH
	return SLOT_PATH % clampi(slot, 1, SLOT_COUNT)


static func has_save(slot: int) -> bool:
	return FileAccess.file_exists(save_path(slot))


## True if the file was written.
static func save_game(slot: int, data: Dictionary) -> bool:
	return _write(save_path(slot), data)


## The saved Dictionary, or an empty one if there is no save or it can't be read.
static func load_game(slot: int) -> Dictionary:
	return _read(save_path(slot))


## The file's text as it is (what Exportar copies), "" if there is none.
static func slot_text(slot: int) -> String:
	if not has_save(slot):
		return ""
	return FileAccess.get_file_as_string(save_path(slot))


## {"kind": SlotKind, "save": the Dictionary, empty unless USABLE}.
static func slot_info(slot: int) -> Dictionary:
	if not has_save(slot):
		return {"kind": SlotKind.EMPTY, "save": {}}
	var save := load_game(slot)
	if not SaveData.is_valid(save):
		return {"kind": SlotKind.DAMAGED, "save": {}}
	return {"kind": SlotKind.USABLE, "save": save}


## True if some slot holds a save Continuar can load.
static func any_usable() -> bool:
	for slot in range(1, SLOT_COUNT + 1):
		if slot_info(slot).kind == SlotKind.USABLE:
			return true
	return false


## True if no slot has a file at all.
static func all_empty() -> bool:
	for slot in range(1, SLOT_COUNT + 1):
		if has_save(slot):
			return false
	return true


## Moves the save of 1.2 and older to slot 1 as it is (a damaged file stays damaged), once:
## never on autoplay runs, and never over a slot 1 that already has a file.
static func migrate_legacy() -> void:
	if OS.get_cmdline_user_args().has("--autoplay"):
		return
	var slot_1 := SLOT_PATH % 1
```

```gdscript
class_name SaveTransfer extends Node
## Moves a save's text between a slot and a file the player keeps. On the web the file is
## downloaded (JavaScriptBridge.download_buffer()) and picked with an <input type=file> made
## from JavaScript; elsewhere a FileDialog asks (the system's own where there is one). Only
## moves text: SaveData.from_json() decides what may come in. Owned by TitleScreen.

signal _web_answered(result: Dictionary)
signal _path_chosen(path: String)

const FILE_NAME := "villaclaro-ranura-%d.json"
const MIME := "application/json"
const FILTER := "*.json ; Partida de Villaclaro"
const EXPORT_TITLE := "Exportar partida"
const IMPORT_TITLE := "Importar partida"
## Bigger files are not saves (a whole game's save is a few tens of KB). PICK_JS repeats it.
const MAX_BYTES := 1000000
const EXPORTED_TEXT := "Partida exportada: %s"
const WRITE_FAILED_TEXT := "No se pudo escribir el archivo."
## Defines window.villaclaroPickSave(done): opens the browser's file picker and calls
## done(picked, text) once; picked is false if the player gave up, text is "" when the
## file can't be read or is too big. No "accept" filter: iOS greys out files it can't type.
const PICK_JS := """
window.villaclaroPickSave = function (done) {
	var input = document.createElement('input');
	input.type = 'file';
	var answered = false;
	function answer(picked, text) {
		if (!answered) {
			answered = true;
			done(picked, text);
		}
	}
	input.addEventListener('cancel', function () { answer(false, ''); });
	input.addEventListener('change', function () {
		var file = input.files && input.files[0];
		if (!file) { answer(false, ''); return; }
		if (file.size > 1000000) { answer(true, ''); return; }
		file.text().then(function (text) { answer(true, text); },
			function () { answer(true, ''); });
	});
	input.click();
};
"""

## Kept while the browser's picker is open: without a reference it would be freed.
var _web_callback: JavaScriptObject


## Writes text to a file the player keeps. Returns the message to show, "" if they gave up.
func export_text(slot: int, text: String) -> String:
	var file_name := FILE_NAME % slot
	if OS.has_feature("web"):
		JavaScriptBridge.download_buffer(text.to_utf8_buffer(), file_name, MIME)
		return EXPORTED_TEXT % file_name
	var path := await _ask_path(FileDialog.FILE_MODE_SAVE_FILE, file_name)
	if path == "":
		return ""
	var file := FileAccess.open(path, FileAccess.WRITE)
	if file == null:
		return WRITE_FAILED_TEXT
	var ok := file.store_string(text)
	file.close()
	return EXPORTED_TEXT % path.get_file() if ok else WRITE_FAILED_TEXT


## {"picked": false} if the player gave up, else {"picked": true, "text": the file's text,
## "" when it can't be read or is too big}.
func import_text() -> Dictionary:
	if OS.has_feature("web"):
		_web_callback = JavaScriptBridge.create_callback(_on_web_file)
		JavaScriptBridge.eval(PICK_JS, true)
		var window = JavaScriptBridge.get_interface("window")
		window.villaclaroPickSave(_web_callback)
		var result: Dictionary = await _web_answered
		_web_callback = null
		return result
	var path := await _ask_path(FileDialog.FILE_MODE_OPEN_FILE, "")
	if path == "":
		return {"picked": false, "text": ""}
	var file := FileAccess.open(path, FileAccess.READ)
	if file == null or file.get_length() > MAX_BYTES:
		return {"picked": true, "text": ""}
	return {"picked": true, "text": file.get_as_text()}


func _on_web_file(args: Array) -> void:
	var picked: bool = args.size() > 0 and args[0] == true
	var text := str(args[1]) if picked and args.size() > 1 else ""
	_web_answered.emit({"picked": picked, "text": text})


## The path the player picks in a FileDialog, "" if they cancel.
func _ask_path(mode: FileDialog.FileMode, file_name: String) -> String:
	var dialog := FileDialog.new()
	dialog.file_mode = mode
	dialog.access = FileDialog.ACCESS_FILESYSTEM
	dialog.use_native_dialog = true
	dialog.filters = PackedStringArray([FILTER])
	dialog.title = EXPORT_TITLE if mode == FileDialog.FILE_MODE_SAVE_FILE else IMPORT_TITLE
	dialog.current_dir = OS.get_system_dir(OS.SYSTEM_DIR_DOCUMENTS)
	if file_name != "":
		dialog.current_file = file_name
	dialog.file_selected.connect(func(path: String) -> void: _path_chosen.emit(path))
	dialog.canceled.connect(func() -> void: _path_chosen.emit(""))
	add_child(dialog)
	dialog.popup_centered_ratio(0.7)
	var path: String = await _path_chosen
	dialog.queue_free()
	return path
```

```gdscript
## The chosen slot's page: its line, Exportar only with a usable save, and message.
func _show_actions(message: String) -> void:
	var info: Dictionary = _infos[_slot - 1]
	_title.text = SLOT_TEXT % _slot
	_detail_line.text = _detail(info)
	_export_button.disabled = info.kind != SaveStore.SlotKind.USABLE
	_message.text = message if message != "" else " "
	_show("actions")


func _on_export() -> void:
	if _busy:
		return
	_busy = true
	_sfx(SfxLibrary.ACCEPT)
	var text := await _transfer.export_text(_slot, SaveStore.slot_text(_slot))
	_busy = false
	if text != "":
		_message.text = text


func _on_import() -> void:
	if _busy:
		return
	_busy = true
	_sfx(SfxLibrary.ACCEPT)
	var file: Dictionary = await _transfer.import_text()
	_busy = false
	if not file.picked:
		return
	var result := SaveData.from_json(file.text)
	if not result.ok:
		_message.text = result.text
		return
	if _infos[_slot - 1].kind == SaveStore.SlotKind.USABLE:
		_ask(IMPORT_CONFIRM % _slot, IMPORT_YES, _write_import.bind(result.save))
	else:
		_write_import(result.save)


func _write_import(save: Dictionary) -> void:
	var ok := SaveStore.save_game(_slot, save)
	_refresh()
	_show_actions(IMPORTED_TEXT % _slot if ok else SAVE_FAILED_TEXT)
	_focus_page("actions")
	if ok:
		changed.emit()
```
