# Versión 1.6.0: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que completar el bestiario tenga premio. Cinco enemigos nuevos, variantes de color de figuras que ya existen (M-31); el álbum se ordena por familias y cada familia vencida entera da una pieza de equipo única; la casilla de Accesorio se parte en Anillo y Amuleto (M-32). El guardado pasa a la versión 11. Spec: `docs/boost/specs/2026-11-09-version-1-6-0-design.md`.

**Architecture:** Los enemigos nuevos son datos (`data/enemies/*.tres`, dos hechizos nuevos en `data/skills/`), cinco `Look` nuevos de `BattleActor` que reutilizan los constructores de slime, seta, murciélago y espectro con otros colores, y una formación más en cada zona. Las familias son una clase pura nueva, `Bestiary` (`FAMILIES`, `family_of()`, `is_complete()`, `new_rewards()`, `give()`), que lee `GameState.defeated_enemies` y apunta cada premio con la bandera del mundo `familia_<id>`; `Game` la consulta tras cada combate ganado y al cargar, y enseña el premio en la ventana de diálogo. `Equipment.ACCESSORY` se sustituye por `RING` y `AMULET`; `Loadout` suma las dos casillas; `SaveData` (versión 11, `RING_VERSION`) pasa el accesorio de un guardado antiguo a la casilla de su pieza. La inmunidad del equipo al sueño y al silencio la da `Combatant.is_immune()` como la del veneno, y `BattleEngine` ahora lo dice con un evento. `BestiaryPage` pinta las familias con su título y su cuenta.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Global Constraints

- **Sin tests de ningún tipo, nunca.** Nada de TDD, ni carpeta `tests/`, ni pasos de "escribe un test que falle". - **Partida real del usuario:** vive en `%APPDATA%\Godot\app_userdata\rpg-turnos\` y no se toca nunca. Toda ejecución de Godot que pueda escribir en `user://` lleva `APPDATA` redirigido a una carpeta del scratchpad **en el mismo comando** (`APPDATA='<scratchpad>\impl\appdata' ./tools/godot.cmd ...`, desde Git Bash). `<scratchpad>` es siempre la ruta literal y completa del scratchpad de la sesión que implementa (por ejemplo `C:\Users\peixe\AppData\Local\Temp\claude\...\scratchpad`): escríbela entera en cada comando. ## Código de partida

La 1.4.1 (`docs/boost/plans/2026-11-09-version-1-4-1.md`) y la 1.5.0 (`docs/boost/plans/2026-11-09-version-1-5-0.md`) se implementan antes que este plan. Lo que este plan pisa de ellas:

- **`BattleEngine._add_status()`** (1.5.0, Task 3, Step 4): tras `var fighter := _fighter(target)` ya tiene el bloque del Despertador (`if _guarded(target, status): events.append(BattleEvent.no_sleep(target)); return`) y después la línea de siempre `if not fighter.is_alive() or fighter.status.has(status) or fighter.is_immune(status): return`. Este plan solo cambia esa última línea (Task 2). `_cast()` ya mira `_guarded()` antes de la tirada; no se toca.
- **`BattleEvent`** (1.5.0): ya tiene `REVIVE`, `WAKE_GUARD` y `NO_SLEEP` con `no_sleep(target)`. Este plan añade `IMMUNE` debajo de `NO_SLEEP` y reutiliza `NO_SLEEP` para el Anillo de savia, así que su mensaje es el mismo: "{nombre} no se duerme.".
- **`BattleScene._play_event()`** (1.5.0): ya tiene los casos `REVIVE`, `WAKE_GUARD` y `NO_SLEEP`. El caso nuevo `IMMUNE` va debajo de `NO_SLEEP`.
- **`BattleScene.setup()`** (1.4.1): ya no añade " A" / " B"; este plan no lo toca.
- **`PauseMenu._fill_spells()`** (1.4.1): ya no pinta la descripción; este plan no lo toca.

## Adaptaciones al spec

- **`BestiaryPage.ORDER` pasa a `Bestiary.FAMILIES`.** El spec pide que `ORDER` sea una lista de familias y, a la vez, que la regla pura viva en `Bestiary` con `FAMILIES`. Se guarda una sola lista, `Bestiary.FAMILIES` (clase pura), y `ORDER` desaparece: la página, el Diario, `Game._note_enemies()` y el generador de retratos leen `Bestiary`. `Bestiary.all_ids()` da los 22 enemigos en orden de familias.
- **La cuenta del título de una familia es de vencidos.** "Plantas 3/4" cuenta los enemigos **vencidos**, porque eso es lo que completa la familia ("Plantas 4/4 · Anillo de savia" sale justo cuando se da el premio). "Bestiario n/22" sigue contando los vistos, como hoy.
- **Mensaje de las inmunidades del equipo.** Hoy la inmunidad al veneno no dice nada (la 1.5.0 lo dejó así). El spec pide que el sueño y el silencio funcionen "como la del veneno" y que salga un mensaje: se hace igual para las tres. El sueño sale con el evento `NO_SLEEP` de la 1.5.0 ("{nombre} no se duerme."); el veneno y el silencio con un evento nuevo `IMMUNE` ("El veneno no afecta a {nombre}." / "El silencio no afecta a {nombre}."). El aviso sale solo cuando el estado habría entrado (tras la tirada), como hoy el estado mismo.
- **"El combate de la página Estado lista las dos".** La página Estado no lista casillas: enseña ATK, DEF y VEL totales, que ya suman el Anillo y el Amuleto. Las seis casillas se listan en la página Equipo, y la línea `Equipo: ...` de la partida automática las nombra todas. No se añade nada a Estado.
- **La Espada del alba va a la bolsa.** La casilla de Arma nunca está vacía (al menos lleva el Palo), así que por la regla general de `QuestRewards` la espada siempre va a la bolsa ("Recibes una Espada del alba. Está en tu bolsa.") y el jugador se la pone desde Equipo. La partida automática no se la pone (el spec: solo si la casilla está vacía).
- **El texto del premio.** La línea es "¡Has completado la familia Plantas del bestiario! " seguida de lo que dice `QuestRewards` de la pieza: "Recibes un Anillo de savia. Te lo equipas." o "... Está en tu bolsa.", como cualquier premio de misión.
- **Columnas en el móvil.** El álbum sigue con su rejilla de `COLUMNS` 6 cromos (más pequeños en el móvil, `TOUCH_CARD_SIDE`), como hoy; cada familia cabe en una fila (la más larga tiene cinco). `TOUCH_HERO_COLUMNS` sigue siendo el de la ventana del héroe, que no cambia.
- **Las salidas de `--autoplay-zone` dan por vencidos sus jefes.** Hoy esas partidas ponen las banderas de los jefes sin apuntarlos como vencidos en el bestiario. Ahora también los apuntan (`defeat_enemy()`), y al empezar también se miran los premios de familia, como al cargar. Así `--autoplay-zone=castillo_trono` da la Espada del alba al vencer al Señor de la Niebla y `--autoplay-zone=eco` la recibe al empezar (va a la bolsa: no cambia sus combates).
- **Dos hechizos nuevos.** "Esporas de sueño más fuertes" es `esporas_cueva.tres` (Esporas, 18 de daño, 50 % de sueño) y "hechizo de hielo a todos" es `ventisca_espectro.tres` (Ventisca, 22 de hielo a todos).
- **El generador de retratos acepta ids.** `scripts/tools/bestiary_shots.gd` lee los ids de los argumentos de usuario y, sin ninguno, hace todos. Así se generan solo los cinco nuevos y los diecisiete de hoy no cambian.

## The bestiary's families: every enemy with a card belongs to one (the Eco de la Niebla
## has none and never counts). A family is complete once every enemy of it has been beaten
## (GameState.defeated_enemies, not only seen); its prize, a piece of equipment of its own,
## is given once (give()) and marked with the world flag "familia_<id>", so the save needs
## no field of its own. Pure: reads and changes a GameState, no nodes.

const FLAG_PREFIX := "familia_"
## In the album's order: id, name, the enemies in order and the prize (an Equipment id).
const FAMILIES: Array[Dictionary] = [
	{"id": "magicas", "name": "Criaturas mágicas",
		"enemies": ["slime", "slime_rojo", "duende", "golem_barro", "slime_metal"],
		"reward": Equipment.CRYSTAL_RING},
	{"id": "plantas", "name": "Plantas",
		"enemies": ["mushroom", "planta", "seta_venenosa", "hongo_cueva"],
		"reward": Equipment.SAP_RING},
	{"id": "bestias", "name": "Bestias",
		"enemies": ["bat", "lobo", "arana", "murcielago_cripta"],
		"reward": Equipment.FANG_AMULET},
	{"id": "muertos", "name": "Muertos vivientes",
		"enemies": ["espectro", "espectro_escarcha", "esqueleto_guerrero", "esqueleto_picaro",
			"esqueleto_mago"],
		"reward": Equipment.BONE_AMULET},
	{"id": "jefes", "name": "Jefes",
		"enemies": ["rey_slime", "bruja", "golem_piedra", "senor_niebla"],
		"reward": Equipment.DAWN_SWORD},
]


## Every enemy with a card, family by family (22).
static func all_ids() -> Array[String]:
	var ids: Array[String] = []
	for entry in FAMILIES:
		for id: String in entry.enemies:
			ids.append(id)
	return ids


## True if enemy_id has a card (and so counts as seen and beaten).
static func has(enemy_id: String) -> bool:
	return family_of(enemy_id) != ""


## The family with family_id ({} if none).
static func family(family_id: String) -> Dictionary:
	for entry in FAMILIES:
		if entry.id == family_id:
			return entry
	return {}


## The id of enemy_id's family ("" for none: the Eco de la Niebla).
static func family_of(enemy_id: String) -> String:
	for entry in FAMILIES:
		if (entry.enemies as Array).has(enemy_id):
			return entry.id
	return ""


## The world flag that says family_id's prize has been given.
static func flag(family_id: String) -> String:
	return FLAG_PREFIX + family_id


## How many enemies of family_id have been beaten.
static func beaten_count(state: GameState, family_id: String) -> int:
	var beaten := 0
	for id: String in family(family_id).get("enemies", []):
		if state.defeated_enemies.has(id):
			beaten += 1
	return beaten


static func is_complete(state: GameState, family_id: String) -> bool:
	var entry := family(family_id)
	return not entry.is_empty() and beaten_count(state, family_id) == entry.enemies.size()


## The families complete whose prize has not been given yet, in album order.
static func new_rewards(state: GameState) -> Array[String]:
	var ids: Array[String] = []
	for entry in FAMILIES:
		if is_complete(state, entry.id) and not state.has_flag(flag(entry.id)):
			ids.append(entry.id)
	return ids


## Gives family_id's prize once: sets its flag and puts the piece on if its slot is empty,
## else into the bag (QuestRewards.give_piece()). Returns the line that says so: "¡Has
## completado la familia Plantas del bestiario! Recibes un Anillo de savia. Te lo equipas."
static func give(state: GameState, family_id: String) -> String:
	var entry := family(family_id)
	state.world_flags[flag(family_id)] = true
	return "¡Has completado la familia %s del bestiario! %s" % [entry.name,
		QuestRewards.give_piece(state, entry.reward)]


## How many families are complete.
static func complete_count(state: GameState) -> int:
	var complete := 0
	for entry in FAMILIES:
		if is_complete(state, entry.id):
			complete += 1
	return complete


## How many enemies with a card have been seen.
static func seen_count(state: GameState) -> int:
	var seen := 0
	for id in all_ids():
		if state.seen_enemies.has(id):
			seen += 1
	return seen
