# Versión 1.1.1: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cerrar los errores y las confusiones de la QA de la 1.1.0 (M-01 a M-06 de `docs/boost/documento-maestro.md`) y lo heredado del móvil (M-23 a M-25).

**Architecture:** Cambios pequeños sobre lo que ya existe. Las reglas siguen en clases puras: la huida prohibida pasa a ser un motivo de `BattleEngine.problem()`, la probabilidad del enemigo raro sale de `EncounterTable` y la migración del bestiario de `SaveData`. La interfaz solo enseña esos resultados. El aviso de la web vive en el HTML del preset, fuera del motor. No hay clases nuevas y el guardado sigue en la versión 9.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Global Constraints

- **Sin tests de ningún tipo, nunca.** Nada de TDD, ni carpeta `tests/`, ni pasos de "escribe un test que falle". Se verifica a mano: `.\tools\godot.cmd --headless --path . --check-only --script res://...`, partidas automáticas (`-- --autoplay`, `--autoplay-zone=...`), capturas y scripts de prueba fuera del repositorio, en el scratchpad.
- Toda ejecución de Godot que pueda escribir en `user://` lleva `APPDATA` redirigido a una carpeta del scratchpad (`$env:APPDATA = "<scratchpad>\appdata"` antes de llamar a `tools\godot.cmd` en PowerShell): la partida real del usuario no se toca. La excepción es exportar la web, que necesita las plantillas del `APPDATA` real y no escribe partidas.
- Juego solo en castellano. Reglas en clases puras (`RefCounted` / `Resource`) sin nodos, escenas como texto con solo la raíz, sin autoloads.
- Mensajes de commit en inglés, sin atribución ni trailer de ningún tipo.
- Gitflow: rama `feature/version-1-1-1` creada desde `develop`, un commit por tarea, merge `--no-ff` a `develop` al final. Sin push ni tags.
- Cada tarea actualiza las líneas de `CLAUDE.md` de lo que cambia.
- En el móvil la pantalla virtual mide unos 1096 × 533 (925 × 450 con "Textos grandes"); se comprueba con `.\tools\godot.cmd --path . --resolution 740x360 ... -- --touch`. `--write-movie` ignora `--resolution`: para capturar a ese tamaño, un script guarda `get_viewport().get_texture().get_image()`. Todo lo que se toque debe caber ahí y tener botones de dedo (`UiStyle.fit_finger()`).
- Guardado: sigue en la versión 9 (`SaveData.VERSION`). Este plan no añade datos al guardado; un guardado anterior debe seguir cargando.
- No se toca `docs/boost/qa/brief-qa-agentes.md` en ningún paso.
- Antes de crear la rama, `git status` en `develop` debe estar limpio. Si no lo está, se para y se pregunta: nunca se commitea directamente en `develop`.

- [ ] **Step 2: `EncounterTable`.** Sustituye el archivo entero por:

```gdscript
class_name EncounterTable extends RefCounted
## Which enemies a random encounter brings, from the zone's ZoneData: within
## start_radius of start_pos only start_formations come (slimes near the meadow's spawn,
## one enemy at a time at the forest's entry); elsewhere every formation of the zone has
## the same weight. The zone's rare enemy comes instead, alone, now and then: at the zone's
## rare_chance while a quest wants it, at RARE_AFTER_QUEST once a quest has hunted it (so
## the bestiary can still be completed), never before its quest is taken. Pure: no nodes.

## The rare enemy's chance once the quest that hunted it is done.
const RARE_AFTER_QUEST := 0.05


static func near_start(zone: ZoneData, pos: Vector3) -> bool:
	return not zone.start_formations.is_empty() and Vector2(pos.x, pos.z).distance_to(
		Vector2(zone.start_pos.x, zone.start_pos.z)) < zone.start_radius


## How often the zone's rare enemy comes now (0..1).
static func rare_chance(zone: ZoneData, wanted: Array[String], hunted: Array[String]) -> float:
	if zone.rare_enemy == "":
		return 0.0
	if zone.rare_enemy in wanted:
		return zone.rare_chance
	if zone.rare_enemy in hunted:
		return RARE_AFTER_QUEST
	return 0.0


## The enemy data of one encounter at pos in zone (not duplicated: BattleScene does it).
## wanted: the enemies an active quest hunts; hunted: those a finished quest hunted.
static func pick(zone: ZoneData, pos: Vector3, rng: RandomNumberGenerator,
		wanted: Array[String] = [], hunted: Array[String] = []) -> Array[Combatant]:
	var chance := rare_chance(zone, wanted, hunted)
	if chance > 0.0 and rng.randf() < chance:
		return EnemyLibrary.formation([zone.rare_enemy])
	var formations: Array = zone.start_formations if near_start(zone, pos) else zone.formations
	return EnemyLibrary.formation(formations[rng.randi_range(0, formations.size() - 1)])
```

`chance > 0.0` antes de tirar el dado: en las zonas sin enemigo raro el generador no gasta una tirada de más, como hoy.
