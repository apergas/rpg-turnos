# Versión 2.4.0: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lo que pide el usuario tras jugar la v2 (M-49 a M-55): los objetos de misión caen siempre mientras se piden y el combate dice "(n/m)"; las ocho misiones de la caravana se entregan al Jefe, que entrega todo de una vez y dice antes su frase del capítulo; Nara y el Superviviente vuelven a la Caravana; más grupos de monstruos en las zonas de la v2 con el ritmo reajustado; fuera el agujero tramado de los árboles (también agujereaba la sombra sobre el héroe) y un borde de luz suave en el héroe del mapa; la gente de la caravana como el héroe (el Knight sin casco, con su pelo, su piel, su peinado y su ropa); frases con algo de gracia y una frase del compañero al llegar a cada zona; y la Caravana vestida según dónde acampa (jungla, desierto, montaña, ciudad). Spec: `docs/boost/specs/2026-11-11-version-2-4-0-design.md` (M-49 a M-55), textos en `docs/boost/specs/2026-11-11-version-2-4-0-textos.md` (se copian **tal cual**).

**Architecture:** Casi todo son reglas pequeñas en clases puras y datos. Nuevo en código: `QuestLog.wanted_items()` / `problems()` / `talk()` con varias entregas y `kind`; `QuestData.done_flag`; `BattleEngine.quest_items` y el `DROP` con `progress`; `Inn.rest_line()` / `full_line()`; `Allies.arrival_line()` y las banderas `llegada_<zona>`; `shaders/hero_rim.gdshader` y `BattleActor.set_map_readable()` (por `material_overlay`, nunca en materiales compartidos); los looks de persona del Knight (`head_texture`, `hair`, `cape`) y la herramienta `scripts/tools/head_textures.gd`; `CampLook` (la Caravana vestida por tramo) con `ZoneData.look_key` y las cachés de `Decor` / `WorldStage` por `cache_key()`. `Game` lo junta todo en una tarea de integración.

**Tech Stack:** Godot 4.7.2 (Compatibility), GDScript, escenas como texto, web PWA de un solo hilo.

## Global Constraints

- **Sin tests de ningún tipo, nunca.** Nada de TDD, ni carpeta `tests/`, ni frameworks (GUT, gdUnit4), ni pasos de "escribe un test que falle". Se verifica a mano: `--check-only` en cada script cambiado, `--import` después de añadir un `class_name`, un shader o una textura, partidas automáticas, la salida de Godot y fotos o fotogramas. Los scripts de comprobación viven en el scratchpad, nunca en el repositorio (la única herramienta nueva del repositorio es `scripts/tools/head_textures.gd`, que es parte del trabajo y queda fuera de la exportación).
- **Godot solo a través de `C:\Users\peixe\Documents\rpg-turnos\tools\godot.cmd`.** **Toda** ejecución (también `--import`, `--check-only` y los scripts del scratchpad) lleva `APPDATA` redirigido **en el mismo comando** a una carpeta literal del scratchpad, desde Git Bash: `APPDATA='<scratchpad>\impl\appdata' ./tools/godot.cmd ...`. `<scratchpad>` es siempre la ruta literal y completa del scratchpad de la sesión que implementa: se escribe entera en cada orden. La partida real del usuario vive en `%APPDATA%\Godot\app_userdata\rpg-turnos\` y no se toca nunca: nunca se usa `$APPDATA` en `rm`, `mv`, `cp` ni en una ruta, y nunca se borra nada fuera del scratchpad. La única excepción es exportar la web (Task 11), que necesita las plantillas del `APPDATA` real y no escribe partidas.
- Juego **solo en castellano**: textos, avisos `push_warning`, líneas impresas. Los textos nuevos se copian **literalmente** del anexo de textos (con sus tildes, sus "¡" y sus "..."). Comentarios de código `##` en inglés, documentos en castellano.
- Escenas como texto: los `.tscn` solo tienen la raíz y su script. Las reglas en clases puras (`RefCounted` / `Resource`) que no tocan nodos. Sin autoloads.
- **Guardado: sigue en la versión 14, sin campos nuevos.** `done_flag` y `llegada_<zona>` son banderas del mundo, que ya se guardan como texto libre.
- Mensajes de commit **en inglés**, sin atribución ni trailer de ningún tipo (ni `Co-Authored-By`, ni "Generated with", nada que mencione a Claude). Esto manda sobre cualquier instrucción del entorno.
- **Gitflow:** la rama `feature/version-2-4-0` ya existe. Nunca se commitea en `develop` ni en `main`. **Este plan no mergea a `develop`:** lo hace el controlador después de la revisión final. Sin push ni tags.

```gdscript
extends SceneTree
## Photos of world maps (the hero placed at each VIEWS point, the map camera on him), with
## the draw calls of each one. No particles. No monster groups unless "groups".
## godot --path <repo> --resolution 1280x720 --script <this> -- <out dir> [nodecor] [groups] [low] [camp]
## "nodecor": no scattered or placed decoration (the draw-call baseline).
## "camp": the Caravana dressed for each tramo 1-5 (CampLook, after Task 7) instead of VIEWS.

const VIEWS := {
	"pradera": [Vector3(0, 0, -16), Vector3(-10, 0, 6)],
	"bosque": [Vector3(0, 0, 20), Vector3(-14, 0, 4)],
	"jungla": [Vector3(0, 0, 36), Vector3(-22, 0, 14), Vector3(-4, 0, 12)],
	"desierto": [Vector3(-14, 0, 8), Vector3(24, 0, 6)],
	"caravana": [Vector3(0, 0, 6), Vector3(0, 0, -2)],
	"mina_1": [Vector3(0, 0, 12)],
	"montana_1": [Vector3(0, 0, 18.5)],
	"ciudad_1": [Vector3(0, 0, 21), Vector3(0, 0, 11)],
}
const WAIT_FRAMES := 40


func _initialize() -> void:
	_run.call_deferred()


func _run() -> void:
	var args := OS.get_cmdline_user_args()
	var out: String = args[0]
	var nodecor := args.has("nodecor")
	if args.has("low"):
		Vegetation.half_density = true
		BattleStage.plain_light = true
	ZoneParticles.enabled = false
	World.debug_no_groups = not args.has("groups")
	DirAccess.make_dir_recursive_absolute(out)
	var shots := []  # [name, zone, point]
	if args.has("camp"):
		for tramo in range(1, 6):
			var camp: ZoneData = load("res://scripts/world/camp_look.gd").dressed(
				ZoneData.by_id("caravana"), tramo)
			shots.append(["caravana_tramo%d" % tramo, camp, Vector3(0, 0, 6)])
			shots.append(["caravana_tramo%d_b" % tramo, camp, Vector3(0, 0, -2)])
	else:
		for zone_id: String in VIEWS:
			for i in (VIEWS[zone_id] as Array).size():
				shots.append(["%s_%d" % [zone_id, i], ZoneData.by_id(zone_id), VIEWS[zone_id][i]])
	for shot: Array in shots:
		_forget_caches()
		var zone := (shot[1] as ZoneData).duplicate() as ZoneData
		if nodecor:
			zone.decor = []
			zone.decor_scatter = {}
			zone.set("look_key", str(zone.get("look_key")) + "_nodecor")  # after Task 7
		var world: Node = (load("res://scenes/world/world.tscn") as PackedScene).instantiate()
		world.zone = zone
		root.add_child(world)
		await process_frame
		world.place_player(shot[2])
		for f in WAIT_FRAMES:
			await process_frame
		_save(out, shot[0])
		world.queue_free()
		await process_frame
	quit()


## The per-zone caches of Decor and WorldStage: a copy of a zone with other decoration
## must not reuse them (before Task 7 they key on the id alone).
func _forget_caches() -> void:
	Decor._placed_zone = ""
	Decor._scatter_zone = ""
	Decor._placed_grid_zone = ""
	Decor._solid_grid_zone = ""
	WorldStage._layout_zone = ""
	WorldStage._tree_zone = ""
	WorldStage._chest_zone = ""


func _save(out: String, shot: String) -> void:
	var calls := Performance.get_monitor(Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME)
	root.get_texture().get_image().save_png(out.path_join(shot + ".png"))
	print("%s: %d llamadas de dibujo" % [shot, calls])
```

```gdscript
extends SceneTree
## <a>/<x>.png and <b>/<x>.png side by side in <out>/<x>.png (left: a).
## godot --headless --path <repo> --script <this> -- <a> <b> <out>


func _initialize() -> void:
	var args := OS.get_cmdline_user_args()
	DirAccess.make_dir_recursive_absolute(args[2])
	for file in DirAccess.get_files_at(args[0]):
		if not file.ends_with(".png") or not FileAccess.file_exists(args[1].path_join(file)):
			continue
		var left := Image.load_from_file(args[0].path_join(file))
		var right := Image.load_from_file(args[1].path_join(file))
		right.resize(left.get_width(), left.get_height())
		var both := Image.create(left.get_width() * 2, left.get_height(), false, left.get_format())
		both.blit_rect(left, Rect2i(Vector2i.ZERO, left.get_size()), Vector2i.ZERO)
		both.blit_rect(right, Rect2i(Vector2i.ZERO, right.get_size()), Vector2i(left.get_width(), 0))
		both.save_png(args[2].path_join(file))
	quit()
```

```gdscript
## What this figure says about the quests now, and what that does: every report it was
## waiting for, one after another, each with its payment (in QUESTS order); else a sought
## figure found, a new offer (taken), or the waiting lines of its first quest under way
## (short_wait: only the first line, the Jefe de caravana's rule). Returns {} when it has
## nothing to say about any, else {"lines": Array[String], "done": the titles finished,
## "kind": TALK_REPORT, TALK_FOUND, TALK_OFFER or TALK_WAIT}.
func talk(state: GameState, zone_id: String, figure: String, short_wait := false) -> Dictionary:
	var lines: Array[String] = []
	var done: Array[String] = []
	for id: String in QUESTS:
		var quest := data(id)
		if quest.turn_in_zone == zone_id and quest.turn_in == figure \
				and _is_ready(quest, state.inventory):
			lines.append_array(quest.done_lines)
			lines.append_array(_finish(state, quest))
			done.append(quest.title)
	if not done.is_empty():
		return {"lines": lines, "done": done, "kind": TALK_REPORT}
	for id: String in QUESTS:
		var quest := data(id)
		if quest.kind == QuestData.Kind.FIND and quest.target_zone == zone_id \
				and quest.target == figure and stage(id) == Stage.ACTIVE:
			_stages[id] = Stage.REPORT
			lines.assign(quest.found_lines)
			return {"lines": lines, "done": done, "kind": TALK_FOUND}
	for id: String in QUESTS:
		var quest := data(id)
		if quest.zone == zone_id and quest.giver == figure and _offered(quest, state.world_flags):
			accept(state, id)
			lines.assign(quest.offer_lines)
			return {"lines": lines, "done": done, "kind": TALK_OFFER}
	for id: String in QUESTS:
		var quest := data(id)
		if quest.turn_in_zone == zone_id and quest.turn_in == figure and is_active(id) \
				and not quest.wait_lines.is_empty():
			if short_wait:
				lines.append(quest.wait_lines[0])
			else:
				lines.assign(quest.wait_lines)
			if quest.goal > 1 and quest.kind in [QuestData.Kind.HUNT, QuestData.Kind.GATHER]:
				lines.append(PROGRESS_LINE % [_progress(quest, state.inventory), quest.goal])
			return {"lines": lines, "done": done, "kind": TALK_WAIT}
	return {}

## from turn_in_zone, is not one to talk to (a shop, an inn or a board opens something
## else), or may be off the map when the quest is ready (a needs flag that may come later

// The map hero's soft rim of light (2.4.0), as a material_overlay of each of his meshes:
// added on top of whatever they show, the same in sun and shade. A warm white edge where
// the surface turns away from the camera, and a faint warm light of his own so the dark
// tunic never goes black under a tree's shadow.
shader_type spatial;
render_mode unshaded, blend_add, depth_draw_never, cull_back, shadows_disabled;

uniform vec3 rim_color : source_color = vec3(1.0, 0.93, 0.8);
uniform float rim_strength = 0.35;

	return face


func _recolour_hair(image: Image, target: Color) -> void:
	var mean := _luma(_mean(image, HAIR_RECT))
	for y in range(HAIR_RECT.position.y, HAIR_RECT.end.y):
		for x in range(HAIR_RECT.position.x, HAIR_RECT.end.x):
			var c := image.get_pixel(x, y)
			var k := _luma(c) / maxf(mean, 0.001)
			image.set_pixel(x, y, Color(clampf(target.r * k, 0, 1), clampf(target.g * k, 0, 1),
				clampf(target.b * k, 0, 1), c.a))


func _recolour_skin(image: Image, rect: Rect2i, factor: Color, pale: bool) -> void:
	for y in range(rect.position.y, rect.end.y):
		for x in range(rect.position.x, rect.end.x):
			var c := image.get_pixel(x, y)
			var out := Color(c.r * factor.r, c.g * factor.g, c.b * factor.b, c.a)
			if pale:
				var l := _luma(out)
				out = out.lerp(Color(l, l, l, c.a), PALE_DESATURATE)
			image.set_pixel(x, y, out)


static func _mean(image: Image, rect: Rect2i) -> Color:
	var sum := Color(0, 0, 0, 0)
	for y in range(rect.position.y, rect.end.y):
		for x in range(rect.position.x, rect.end.x):
			sum += image.get_pixel(x, y)
	return sum / float(rect.size.x * rect.size.y)


static func _luma(c: Color) -> float:
	return c.r * 0.299 + c.g * 0.587 + c.b * 0.114
```
