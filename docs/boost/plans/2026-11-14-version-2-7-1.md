# Versión 2.7.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `docs/boost/design-system/tokens.json` the one source of the UI: `scripts/ui/ui_tokens.gd` is generated from it in full, a check tool forbids hand-written UI values, and a git hook plus the Pages workflow keep both from drifting. The spec is [2026-11-14-version-2-7-1-design.md](../specs/2026-11-14-version-2-7-1-design.md).

**Architecture:** Two tool scripts in `scripts/tools/` (already excluded from the export): `gen_ui_tokens.gd` (JSON → `ui_tokens.gd`, `--check` mode) and `check_ui_values.gd` (scan for literal UI values). A versioned `.githooks/pre-commit` and a step in `.github/workflows/pages.yml` run both. Then the hand-written values move into tokens, and the docs follow.

**Tech Stack:** Godot 4.7.2 GDScript (tools run with `--headless --path . --script res://scripts/tools/<x>.gd`), JSON, bash for the hook, GitHub Actions.

## Global Constraints

- NO TESTS, EVER: no `tests/` folder, no test frameworks. Verify with the tools themselves, `--check-only`, `--import`, autoplay runs and `--write-movie` frames.
- No visible change for the player: every token keeps today's value. The save stays at version 14.
- The generated `ui_tokens.gd` keeps every public name and value it has today: `high_contrast`, `JUEGO`, `ALTO_CONTRASTE`, `color()`, `SPACE_*`, `RADIUS_*`, `BORDER_*`, `OUTLINE_*`, `TOUCH_TARGET` and the other size constants, `LAYER_*`, `OPACITY_*`, `TYPE_*_SIZE` / `TYPE_*_WEIGHT`, `FONT_DISPLAY_PATH`, `FONT_UI_PATH`, `SHADOW_COLOR`, `SHADOW_SIZE`, `SHADOW_OFFSET`, `FAMILY_DISPLAY`, `FAMILY_UI`, `TYPE`, `type_size()`. Names are derived from token names: `space-4` → `SPACE_4`, `opacity-faded` → `OPACITY_FADED`, `layer-hud` → `LAYER_HUD`, `touch-target` → `TOUCH_TARGET`.
- The tools use no game `class_name` (they run with `--script`, before the class cache matters) and follow the GDScript style guide (typed, `##` doc comments).
- Every Godot run that could touch `user://` sets `APPDATA` inline to `C:\Users\peixe\AppData\Local\Temp\claude\45465eb600abb7f8\093ace1b-1d9c-48e8-820b-b03145925ca1\scratchpad\appdata`. Never use `$APPDATA` in rm/mv/cp, and never touch the real save folder.
- Gitflow: work on `feature/version-2-7-1` from `develop`. No push, no merge. Commit messages never mention Claude.
- Design-system docs are in Spanish; code comments in English, as in the rest of the code.
- Update CLAUDE.md in the same commit as the code it describes (skill rule).

- [ ] **Step 3: The generator**

`scripts/tools/gen_ui_tokens.gd` (`extends SceneTree`, `_init()`):
- Parses the JSON (`JSON.parse_string(FileAccess.get_file_as_string(...))`).
- Builds the text of `ui_tokens.gd`:
  - header: `class_name UiTokens extends RefCounted` and a `##` comment saying it is generated by `scripts/tools/gen_ui_tokens.gd` from `docs/boost/design-system/tokens.json` and must never be edited by hand;
  - `static var high_contrast := false`;
  - `const JUEGO` and `const ALTO_CONTRASTE` with every colour token, `{ref}` values resolved recursively. Single-value tokens go into both; two-theme tokens give each its own. `ALTO_CONTRASTE` may hold only the tokens that differ, as today, so `color()` keeps its fallback;
  - `color()`;
  - the constant groups (spacing, radius, border, outline, size, layer, opacity) with px stripped to ints and opacities as floats;
  - the `TYPE_*_SIZE` / `TYPE_*_WEIGHT` constants;
  - `FONT_*_PATH`;
  - `SHADOW_*`, `FAMILY_*`, `TYPE`, `type_size()`.

  Match today's file closely: same order, same names, same values, `&"..."` StringName keys, `Color("#rrggbb[aa]")` literals. Sort nothing that today's file keeps in JSON order.
- Normal mode writes the file. With `--check`, it compares and exits 1 on a difference.
- Output always ends with one newline and uses tabs, so regeneration is byte-stable.

Run it, then `git diff scripts/ui/ui_tokens.gd`. The only acceptable differences are the header comment and the removal of the "game's own" wording: every constant and value must be the same. Run it a second time with `-- --check`; expected exit 0.

- [ ] **Step 4: The check tool**

`scripts/tools/check_ui_values.gd` (`extends SceneTree`):
- Walks `res://scripts/` recursively (`DirAccess`) over `.gd` files.
- For each line, ignoring comment-only lines (stripped line starting with `#`), it reports:
  1. `Color(` in a file under `scripts/ui/` (except `scripts/ui/ui_tokens.gd`) or under `scripts/title/`;
  2. `add_theme_color_override(` with `Color(` on the same line, anywhere;
  3. `add_theme_font_size_override(` whose size argument is a number literal, or `font_size = <number>`, anywhere.
- It prints `path:line: reason` for each hit and exits 1 if there was any, else prints `Valores de interfaz: sin valores a mano` and exits 0.
- At this point of the plan it is expected to FAIL on the hand values Task 2 removes (`scripts/ui/name_entry.gd` `Color(1, 1, 1, EMPTY_ALPHA)`, `scripts/title/title_screen.gd` `Color(0, 0, 0, 0)`). - [ ] **Step 1: The hook**

`.githooks/pre-commit` (bash, LF line endings, executable bit set with `git update-index --chmod=+x`):
- It does nothing unless the staged files (`git diff --cached --name-only`) include `docs/boost/design-system/tokens.json` or a `.gd` file.
- It picks Godot: `tools/godot.cmd` if it exists (Windows clone), else `godot` on PATH. If neither exists, it prints a warning and exits 0 (CI still guards).
- It runs the generator with `-- --check` and `check_ui_values.gd`, both `--headless --path .`. If either fails, it prints what to do ("Ejecuta gen_ui_tokens.gd y añade ui_tokens.gd" / fix the listed lines) and exits 1.

Activate it here: `git config core.hooksPath .githooks`.

Test on a throwaway branch: change one colour in `tokens.json` without regenerating and try to commit; expected: the hook blocks it. Then regenerate; expected: the commit goes through. Delete the throwaway branch (`git checkout feature/version-2-7-1 && git branch -D <it>`) so nothing of it stays.
